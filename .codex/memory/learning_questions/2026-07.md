- answer_summary: exc 是 except 捕获到的原始 HTTPX 异常对象。raise RuntimeError("...") from exc 会抛出一个新的、更适合业务层理解的 RuntimeError，并明确声明原始 exc 是它的直接原因。这样既统一了对外错误信息，又保留了底层网络错误的 traceback 和异常链，调试时可以继续追溯真实原因。

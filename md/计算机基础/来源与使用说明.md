## 技术事实怎样核对

- Python 例子目标为 3.12+，行为优先核对 Python 3.12 官方参考；明确标注 3.13 新增或变化处，不把最新文档的类形态套到旧版。
- 标准库模块无需作为第三方依赖安装；具体解释器仍可能缺少可选模块，例如某些发行版中的 sqlite3。遇到导入失败先核对解释器和发行版，不直接安装同名 PyPI 包。
- 网络语义参考 IETF RFC，SQLite 行为参考 SQLite 与 Python 官方文档；每章末尾给出对应链接。
- 官方更新与社区解释冲突时以匹配版本的官方资料为准。社区翻译可能落后于原课，不把旧译文当作当前提交要求。

## 验证能证明什么

可执行课堂例子应与程序实际输出一致。源码语法通过、本地例子通过、学习者独立完成、官方课程通过，是四件不同的事。

具体运行环境、检查结果和未验证项统一记录在[本次校验记录](../../docs/computer-foundations-validation.md)。本机回环 HTTP 不验证公网 DNS、TLS、路由或生产部署；文件库重开实验不验证断电耐久性；没有替学习者完成综合项目或官方判题。

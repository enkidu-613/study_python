# 00. 补基础要补到哪里

你现在的问题不是“会的东西全部不算数”，而是有些机制在使用框架时被隐藏了。补基础要让你能解释、选择和排错，不是重新收集一遍所有语言的语法。

本章只确定学习顺序和验收方式；不开始讲操作系统内部算法，也不增加必须先通过的数学考试。

## 1. 先把三个目标分开

- **编程入门**：能把一个小需求拆成数据、函数、分支与循环，并验证结果。CS50P 服务这个目标。
- **计算机科学入门**：能讨论数据表示、算法开销、内存与常用结构，并通过练习检验理解。CS50x 是这一层的正式课程入口。
- **应用开发能力**：能把程序做成可运行、可维护的服务，处理网络、数据与失败。这要继续在当前后端与 AI 项目里练。

三者有关联，但没有哪一门课能自动替你完成另外两项。读完讲义、通过课程、能够胜任工作，也不是同一个结论。

## 2. 你接下来具体怎么做

1. 先完成正在热身的 CS50P。熟悉的单元以独立练习确认，不强迫慢速重看。
2. 接 [CS50x 中文课程](CS50x/README.md)，按目录中的周次学习；原 [01 章](01_CS50x_计算机科学入门.md)保留为简短导览。重点保留 C、数组、算法、内存和数据结构，不因平时用 Python 就跳过。每章先运行课堂例子、追踪过程，再做自己的改动和独立练习。
3. 做本目录 02–07 的应用练习。它们把官方课中的部分基础接回文档查询业务，也补充 CS50x 不会完整展开的系统与网络内容。
4. 做 08 章的小项目，带着实际结果回到 AI 主线。不必等读完操作系统或网络的整本教材才继续开发。

这是针对你的推荐顺序，不是 Harvard 规定必须先 CS50P 后 CS50x。

## 3. 各章究竟推进什么

| 项目当前状态 | 本章新增能力 | 用到的已有知识 | 本章新内容 | 验收证据 | 下一章继续用什么 |
| --- | --- | --- | --- | --- | --- |
| 会运行 Python 文件 | 02 定位运行失败 | 文件、函数、异常 | 进程返回码与输出渠道 | 故意失败后说出原因 | 可观察的运行结果 |
| 用列表存三篇文档 | 03 按查询需求组织数据 | list、dict、set | 队列、栈、结构约束 | 查询、缺失、重复 ID 都有结果 | 文档记录与 ID |
| 能查到文档 | 04 比较不同查找方法 | 循环、条件、函数 | 比较次数与增长量 | 同一批数据对照步骤数 | 查找函数 |
| 程序只在一个进程运行 | 05 观察资源和生命周期 | 变量、with | 进程、线程、文件资源 | 子进程、共享数据、文件读写实验 | 服务运行的边界 |
| 查询只能在程序内部调用 | 06 从本地 HTTP 读取文档 | 类、JSON、异常 | 服务地址与请求响应 | 正常请求及 404 | 方法、路径与响应约定 |
| 数据只放在普通变量里 | 07 建表并保证成组写入 | 基本 SQL | 关系、约束、索引、事务 | JOIN 查询和回滚结果 | 可替换的查询层 |
| 各部分分开验证过 | 08 自己组合程序 | 前面所有能力 | 接口之间的责任划分 | 自己的测试、运行说明与排错记录 | 回到 FastAPI/RAG 项目 |

02–07 的完整例子是课堂实验，不是综合作业的现成解答。08 要求你自己接起来，这一步才能发现“每段都看懂”与“能自己组织”之间的差别。

## 4. 怎样证明这节真的懂了

每章都问四件事，不要求背标准措辞：

1. 它是什么？能指着程序里的对象或操作说明。
2. 它解决什么问题？能举本章文档业务的例子。
3. 为什么选它？能说明一个常见替代方案什么时候更合适。
4. 怎么验证？能改一个输入，预测并核对实际结果。

例如“字典很快”还不够。你需要能解释：按唯一 ID 查询时，用 ID 作键可以避免每次逐个遍历；建立映射要时间和额外内存，重复 ID 还必须明确处理，不能把这些成本当作不存在。

## 5. 入门验收不是凭感觉打勾

本目录采用以下学习标准，不是统一的行业认证：

- 不照着完整答案，也能实现小需求并写出关键测试。
- 能追踪输入到输出，说明函数、网络和数据库分别在哪里工作。
- 遇到错误能先分类、收集证据，再缩小范围，不只随机换配置。
- 能用简单例子解释时间开销、内存与文件、索引与事务的区别。
- 能查官方文档解决陌生 API 问题，不必记住每个参数的拼写。

CS50x 的官方完成与证书要求另按[课程大纲](https://cs50.harvard.edu/x/syllabus/)及评阅页面核对。本地补充练习不代替官方作业，也不会给出“相当于本科毕业”的判断。

## 6. 哪些东西现在先不展开

本轮不要求：复杂动态规划题、完整编译器、内核源码、网络拥塞算法、数据库分布式一致性证明，以及深度学习训练推导。它们有价值，但不是本轮每个实验的前置条件。

以后按需要继续加深：

| 经常碰到的问题 | 下一步加深方向 |
| --- | --- |
| 数据量一大查询就慢 | 数据结构、算法和数据库执行计划 |
| 服务卡住、内存上涨、并发出错 | 操作系统、并发与资源管理 |
| 请求超时、代理和证书问题 | 计算机网络与 TLS |
| AI 检索效果差、想理解模型计算 | 线性代数、概率统计及对应 AI 原理 |

数学按实际主题补：复杂度先理解“翻倍后多做多少步”，向量计算再补矩阵与点积。这里不让你先补完高等数学才能查一篇文档。

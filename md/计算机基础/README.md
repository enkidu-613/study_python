# 计算机基础：从会写代码到能解释程序

你不需要先补齐整个本科课程才能继续做 AI 应用。这组文档帮助你在 CS50P 之后，理解程序怎样运行、数据怎样组织、请求怎样到达服务，以及结果怎样可靠地保存。

先分清三个层次：**CS50P 学 Python，[CS50x 中文课程](CS50x/README.md)按官方周次学习计算机科学入门，本目录 02–08 将基础用回你熟悉的后端场景。** 中文课程包含逐章代码、解释和练习，但不替代官方视频、问题集评阅，更不是学校学历或就业资格的替代品。

## 练习怎样衔接

02–08 使用同一个业务：保存几篇知识文档，按 ID 查询，区分归属，再通过本地接口读取。它只管理文档目录，不调用向量模型或大模型，避免额外费用和部署问题遮住基础。

练习位置：[examples/cs-foundations](../../examples/cs-foundations/README.md)。每章完整示例自带数据，不依赖上章生成的临时文件；你最后再将能力整合到自己的程序。

本目录的章节号是独立编号，不改动原有 AI 主线的第 33 章等编号，也不自动将任何阶段标记完成。

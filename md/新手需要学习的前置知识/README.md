# AI 应用开发：零基础自学前置课程

这是一条给完全新手的文字自学路线：不需要截图、不需要视频，也不需要先懂编程。每章只完成一个动作；完成检查点再读下一章。

| 设备 | 终端 |
| --- | --- |
| Windows 10/11 | PowerShell，不要求 WSL |
| macOS | Terminal（zsh） |
| Linux | Terminal（Bash） |

遇到系统命令时，只复制自己系统对应的一列；Python 代码、Git 概念与练习三端相同。

## 顺序

`00–06` 建立并运行程序 → [按 CS50P 单元学习 Python 基础](CS50P_Python基础学习路线.md) → `19–23` 保存并上传代码 → `24–26` 理解 Web 与数据 → `27` 进入现有 AI 应用主线。

Python 基础部分以 Harvard University 的 **CS50’s Introduction to Programming with Python（CS50P）** 为主题骨架，使用本项目的中文解释、学习待办示例和独立练习。现有 `07–18` 文件继续使用；新增单元补充单元测试、正则表达式和常用 Python 写法。阅读顺序以路线表为准，文件编号保留供旧链接查找。

原课程：**David J. Malan 与 CS50 团队，Harvard University**。[官方课程](https://cs50.harvard.edu/python/) · [署名、改编范围与 CC BY-NC-SA 4.0 许可](CS50P_来源与许可.md)。这是非官方中文改编导学，不表示 Harvard 或 CS50 对本项目背书。

完成后从 [项目环境配置](../00_环境配置与PyCharm使用.md) 开始。不要跳过 `03`、`06`、`13`、`15–23`：它们解决新手最常见的“为什么跑不起来/为什么传不上去”。

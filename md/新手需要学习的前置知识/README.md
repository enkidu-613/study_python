# 从 CS50P 到 AI 应用开发：前置课程入口

Python 入门直接从下面的 CS50P 课程目录开始：课程内部已经提供必要环境准备，按 0–9 顺序学习，再完成 Final Project。本目录其他文件提供更详细的工具参考、计算机基础和工程衔接，不是进入 CS50P 前必须完成的一组课程。

| 设备 | 终端 |
| --- | --- |
| Windows 10/11 | PowerShell，不要求 WSL |
| macOS | Terminal（zsh） |
| Linux | Terminal（Bash） |

遇到系统命令时，只复制自己系统对应的一列；Python 代码、Git 概念与练习三端相同。

[CS50P：课程内环境准备 → 0–9 → Final Project](CS50P/README.md) → [CS50x 与计算机基础](../计算机基础/README.md) → `19–27` 按需查阅工程衔接 → AI 应用主线。`00–06` 是可选的详细工具参考；已会的 Git、HTTP、SQL 不机械重学。

## 第二阶段：CS50P Python 课程

从 [CS50P 课程目录](CS50P/README.md) 进入，第一篇是 [00. 函数与变量](CS50P/00_函数与变量.md)。十个单元对应官方讲义，课堂示例按中文重新解释，作业直接使用官方问题集。原有 `07–18` Python 讲义、单元对照表与自编结课题已由这套课程替换。

原课程：**David J. Malan 与 CS50 团队，Harvard University**。[官方课程](https://cs50.harvard.edu/python/) · [来源、中文改编与 CC BY-NC-SA 4.0 许可](CS50P/来源与许可.md)。本目录的 CS50P 讲义为非官方中文改编。

## 第三阶段：计算机基础

进入[计算机基础目录](../计算机基础/README.md)：先按 CS50x 官方周次理解表示、算法、内存与数据结构，再通过中文补充实验把工具、算法、操作系统、网络和数据库接起来。每章有实际结果和练习，最后做小型文档目录服务验收。

这是给当前学习者的补基础安排，不要求所有新手先补完这些才准写应用。CS50x 指引不是完整译本，本地实验也不代替官方问题集；已完成的 AI 学习进度不重置。

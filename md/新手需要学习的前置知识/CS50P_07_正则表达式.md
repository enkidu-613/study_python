# CS50P 单元 7：验证有固定格式的文本

> 原课程：David J. Malan 与 CS50 团队，Harvard University，[CS50P Regular Expressions](https://cs50.harvard.edu/python/notes/7/)。本讲义由 enkidu-613 中文改编并加入项目示例，按 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 分享。[来源与许可](CS50P_来源与许可.md)。

前置：字符串、函数、条件、模块和测试。目标：识别 `TASK-` 后面恰好三个 ASCII 数字的编号；暂不编写通用邮箱或网址校验器。

## 从具体输入开始

```python
import re


def is_task_code(text: str) -> bool:
    return re.fullmatch(r"TASK-[0-9]{3}", text) is not None


print(is_task_code("TASK-001"))
print(is_task_code("TASK-01"))
print(is_task_code("TASK-001-extra"))
```

预计依次输出 `True`、`False`、`False`。同一函数已放在 [task_tools.py](../../examples/python-basics-cs50p/task_tools.py)，可用上个单元的命令运行它的测试。

`re` 是 Python 标准库，无须安装。正则表达式（regular expression）是描述文本模式的字符串；`re.fullmatch(pattern, text)` 是模块函数，检查整个输入是否符合该模式。成功返回匹配对象，失败返回 `None`，所以 `is not None` 把结果变成布尔值。

| 模式片段 | 本例含义 |
| --- | --- |
| `TASK-` | 按字面匹配这五个字符 |
| `[0-9]` | 一个 ASCII 数字 |
| `{3}` | 前一个模式恰好重复三次 |
| `r"..."` | Python 原始字符串写法，减少反斜杠被 Python 提前转义的情况；本例本身没有反斜杠 |

不需要正则时继续用字符串操作：去除空白用 `strip()`，只查前缀用 `startswith()`。组合格式开始难以读清时，再用模式表达规则。

## 改动与边界

把 `{3}` 改成 `{2,4}`，再预测 `TASK-01` 和 `TASK-00001` 的结果。`fullmatch` 要求全部字符匹配，所以额外前后缀和末尾换行都不能混过去。当前规则也不接受全角数字；这是本例对编号格式的明确约束。

独立练习：给 `TASK-000`、`TASK-999`、`OTHER-001`、`TASK-１２３` 分别写测试，先预测再运行。每条测试说明它验证的是哪条规则。

检查点：能指出 `re`、函数、模式字符串和返回值；能解释为什么使用 `fullmatch`；能修改数字位数；能拒绝多余字符。

# CS50P 单元 5：让测试检查函数结果

> 原课程：David J. Malan 与 CS50 团队，Harvard University，[CS50P Unit Tests](https://cs50.harvard.edu/python/notes/5/)。本讲义由 enkidu-613 中文改编并加入项目示例，按 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 分享。[来源与许可](CS50P_来源与许可.md)。

前置：函数、条件、异常、模块。目标：检查同一个标题处理函数在正常和错误输入下的行为；暂不测试网络、数据库或 AI 模型。

## 先运行一次

在本项目根目录运行：

```bash
poetry run python -m pytest examples/python-basics-cs50p/test_task_tools.py -q
```

`pytest` 是第三方测试工具；本项目已经有这项开发依赖。`python -m pytest` 用当前 Python 启动它，避免把别的环境里的测试工具拿来运行。本例只使用本地字符串和数字，不启动 FastAPI。若在自己的独立练习项目中跟写，需要先在该虚拟环境安装 `pytest`。

打开 [被测函数](../../examples/python-basics-cs50p/task_tools.py) 和 [测试文件](../../examples/python-basics-cs50p/test_task_tools.py)。先只看 `normalize_title` 与名称包含 `normalize_title` 的测试；其余测试留给对应单元。

```python
def normalize_title(title: str) -> str:
    cleaned = title.strip()
    if cleaned == "":
        raise ValueError("任务标题不能为空")
    return cleaned
```

函数接收字符串，返回去掉两端空白的标题；全部是空白时抛出异常。清理规则写在一个函数里，后面的命令行、文件导入或接口都可以复用。

## 谁调用谁

```python
import pytest

from task_tools import normalize_title


def test_normalize_title_removes_outer_spaces():
    assert normalize_title("  学习 Python  ") == "学习 Python"


def test_normalize_title_rejects_blank():
    with pytest.raises(ValueError):
        normalize_title("   ")
```

1. `pytest` 找到 `test_` 开头的文件与函数，调用测试函数。
2. 测试函数调用 `normalize_title`，取得返回结果。
3. `assert` 是 Python 语句：条件为真时继续，条件为假时抛出 `AssertionError`，pytest 将该测试记为失败。
4. `pytest.raises(ValueError)` 返回一个可用于 `with` 的检查对象；离开代码块时确认里面是否抛出了预期异常。没抛出就失败，抛出其他异常也失败。

`assert` 适合测试预期，不能替代业务输入校验：Python 优化模式可能移除断言。函数里拒绝空标题仍用 `if` 和 `raise`。

这里测试文件与 `task_tools.py` 放在同一目录，pytest 按其默认导入方式找到该模块。独立跟写也先保持两个文件同目录，避免同时处理包路径问题。

## 亲手证明测试有用

把第一个测试右边的预期改成 `"错误标题"`，再次运行，应出现失败和实际值对比。改回后再运行，应全部通过。测试失败证明预期与实际不一致，还需要检查是函数错了还是预期写错了。

独立练习：新增一个测试，输入 `"学习 Python"` 时原样返回；再新增一个测试，输入空字符串时抛出 `ValueError`。不要给现有函数加“为了让测试通过”的特殊判断。

检查点：能指出被测函数与测试函数；能解释正常返回和抛异常分别怎样验证；故意写错预期后见到失败；修正后再通过。

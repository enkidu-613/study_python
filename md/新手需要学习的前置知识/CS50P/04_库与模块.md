## 1. Libraries：先借用一段能力

把下面内容放入 `generate.py`，运行 `python generate.py`：

```python
import random

coin = random.choice(["heads", "tails"])
print(coin)
```

程序先导入标准库 `random` 模块，再由当前程序调用其中的 `choice` 函数。
输入是含两个字符串的列表；返回其中一个字符串；`print` 把返回值写到终端。
一次结果只能是其中一个，不能通过“连续两次不同”来验证随机性。

**库（library）**泛指可复用代码集合；**模块（module）**是可导入的代码单元，常见形式是一个 `.py` 文件。
`import` 是语句，不是安装命令，也不是把所有函数都执行一遍。
`random.choice` 中的点表示从模块对象上取得名为 `choice` 的属性，然后圆括号发起调用。

## 2. Random：名称、返回值与原地修改

`generate.py` 的另一种完整写法：

```python
from random import choice

print(choice(["heads", "tails"]))
```

`from random import choice` 把 `choice` 这个名字直接绑定在当前模块中。
它不表示“只加载模块的一小块”，也不改变随机算法；区别主要在调用时使用的名字。
优先用明确的导入；不要用 `from random import *` 掩盖名称来源。

下面替换成掷骰子，仍运行 `python generate.py`：

```python
import random

number = random.randint(1, 6)
print(number)
```

`randint(a, b)` 的返回值是整数，包含两个端点，所以 `6` 也可能出现。
不要把这里的包含上界与 `range` 的不包含上界混为一谈。

接着创建 `cards.py`：

```python
import random

cards = ["jack", "queen", "king"]
result = random.shuffle(cards)
print(cards)
print(result)
```

`shuffle` 接收可修改的列表，**原地修改（in-place）**这个列表，返回 `None`。
因此牌要从 `cards` 读取，不能写成 `cards = random.shuffle(cards)`。
改动验证：增加一张牌，检查洗牌后元素仍相同；随机洗牌也可能保持原顺序。
`random` 适合课堂模拟、游戏抽签，不适合生成密码或安全令牌；安全用途另有 `secrets`。
本节行为边界见 [random 官方文档](https://docs.python.org/3/library/random.html)。

## 3. Statistics：平均值也可以复用

创建 `average.py`：

```python
import statistics

scores = [100, 90]
average = statistics.mean(scores)
print(average)
```

运行 `python average.py`，这里得到 `95`。
`statistics` 是标准库，处理基本统计；`mean` 是其中的函数，接收数值数据，返回算术平均值。
用于成绩平均、简单测量汇总；它不会替你清洗非数值文本，也不是完整的数据分析平台。
已知少量数值也可手算；使用标准函数能把“我要平均值”的意图写清楚。
边界：空列表没有算术平均值，`statistics.mean([])` 会抛出 `StatisticsError`。
先预测加入 `80` 后的结果，再运行验证；不要假设结果永远是整数。

## 4. Command-Line Arguments：启动时传入姓名

创建 `name.py`：

```python
import sys

print(sys.argv)
print("hello, my name is", sys.argv[1])
```

运行 `python name.py David`，第一行类似 `['name.py', 'David']`，下一行是问候。
`sys` 是标准库模块，提供解释器相关状态；`argv` 是它维护的字符串列表，不是函数。
调用链：终端启动解释器 → 解释器设置 `sys.argv` → 你的程序索引列表 → 输出姓名。
`sys.argv[0]` 在这种启动方式下是脚本路径；`sys.argv[1]` 才是第一个用户参数。
参数都是字符串；传入 `100` 不会自动得到整数。多词姓名要用引号：`python name.py "David Malan"`。

不传姓名会怎样？运行 `python name.py`，观察 `IndexError` 和出错行。
`IndexError` 表示序列索引越界，不是 `ValueError`，也不是变量不存在。
先以异常方式保护访问，完整替换 `name.py`：

```python
import sys

try:
    print("hello, my name is", sys.argv[1])
except IndexError:
    print("Too few arguments")
```

这能处理缺少姓名，但还没有拒绝多余参数。把“参数个数”作为契约更清楚：

```python
import sys

if len(sys.argv) < 2:
    sys.exit("Too few arguments")
elif len(sys.argv) > 2:
    sys.exit("Too many arguments")

print("hello, my name is", sys.argv[1])
```

`sys.exit` 是函数，通过抛出 `SystemExit` 请求退出；这里没有捕获它，后续问候便不会执行。
字符串参数会作为错误信息输出并产生非零退出状态；`sys.exit()` 或 `sys.exit(0)` 通常表示正常退出。
与 `return` 不同，它不是只从当前函数返回。也不要笼统说它能无条件终止所有线程。
如果只写 `print("Too few arguments")` 而仍继续索引，错误检查就没有阻止后续越界。
验证三种启动：无姓名、一个姓名、两个姓名，只有中间一种应该问候。
这些解释器行为参照 [sys 官方文档](https://docs.python.org/3/library/sys.html)。

## 5. Slices：跳过脚本名，而不是修改原列表

创建 `names.py`：

```python
import sys

if len(sys.argv) < 2:
    sys.exit("Too few arguments")

for name in sys.argv[1:]:
    print("hello, my name is", name)
```

运行 `python names.py David Carter Rongxin`，应有三行问候，不包括 `names.py`。
**切片（slice）**的常用语法是 `sequence[start:stop]`，包含起点，不包含终点。
`[1:]` 省略终点，取索引 1 到末尾；`[:2]` 取前两项；`[1:3]` 取索引 1、2。
对列表切片会得到新列表，不会删除原列表的元素；`sys.argv[1:]` 是表达式，不是一条 `slice` 命令。
单项索引越界会报错，但无用户参数时 `sys.argv[1:]` 是空列表。
这里仍检查参数数目，是为了告诉使用者“你忘了输入”，而不是因为空切片会报错。

## 6. Packages：安装与导入是两件事

以下命令仅供学习者在已激活的独立练习环境执行，本文没有替你安装，也不修改 `pyproject.toml`：

```bash
python -m pip install cowsay requests
python -m pip show cowsay requests
```

`pip` 是安装工具，PyPI 是发布 Python 分发包的索引；`python -m pip` 让当前解释器运行对应的 pip。
**包（package）**在导入语境中组织模块；安装用的“分发包”名称与导入名不保证相同。
第三方包不随标准库提供。只从可信来源安装；若复用当前 Poetry 项目，先确认其已有依赖，用 `poetry run python 文件名.py` 运行，不在其中照抄上面的 pip 安装命令。

创建 `say.py`；这是第三方 `cowsay` 的课堂演示，不是前面的自建模块：

```python
import sys

import cowsay

if len(sys.argv) != 2:
    sys.exit("Usage: python say.py NAME")

cowsay.cow("hello, " + sys.argv[1])
```

运行 `python say.py David`，目标是终端出现带问候语的字符画。
`cowsay.cow` 是函数，输入字符串，效果是打印字符画；本例不依靠其返回值。
把 `cow` 改为 `trex` 体验同一包的另一个函数；包职责是文字展示，不负责交互输入或网络通信。
普通问候用 `print` 即可；此处是学习安装和调用，不是说字符画是程序必需品。
若出现 `ModuleNotFoundError`，先核对解释器与安装位置，不要用同名 `.py` 文件“补”第三方包。
所需接口与安装名参见 [cowsay 的 PyPI 页面](https://pypi.org/project/cowsay/)，不宣称本仓库已安装某版本。

## 7. APIs：先观察响应，再选取字段

创建 `itunes.py`，需要刚才的第三方 `requests` 与可访问外网的环境：

```python
import json
import sys

import requests

if len(sys.argv) != 2:
    sys.exit('Usage: python itunes.py "ARTIST"')

try:
    response = requests.get(
        "https://itunes.apple.com/search",
        params={"entity": "song", "limit": 3, "term": sys.argv[1]},
        timeout=10,
    )
    response.raise_for_status()
    data = response.json()
except requests.RequestException as error:
    sys.exit(f"Request failed: {error}")
except ValueError as error:
    sys.exit(f"Invalid JSON: {error}")

print(json.dumps(data, indent=2, ensure_ascii=False))
for result in data["results"]:
    print(result["trackName"])
```

运行 `python itunes.py weezer`；预期先看到格式化数据，再看到最多三条歌曲名，具体内容不固定。
API 是应用程序编程接口：此处服务器接受约定参数，返回约定数据；不是 Python 特有的对象类型。
`requests` 是第三方 HTTP 客户端，适合查询外部服务或下载响应，不会像浏览器一样执行网页 JavaScript。
`requests.get` 是函数，输入地址、查询参数和超时，返回 `Response` 实例，变量 `response` 指向它。
`params` 字典由库编码进 URL 的查询字符串，避免手工拼接姓名中的空格等字符。
`timeout=10` 限制连接/读取等待，不保证整个请求总耗时恰为十秒；网络仍可能失败。
`response.raise_for_status()` 是实例方法；遇 HTTP 错误状态会抛异常，成功解码 JSON 本身不代表 HTTP 成功。
`response.json()` 是另一个实例方法，将响应正文解析成 Python 对象；该服务的顶层对象预期为字典。

JSON 是交换数据的文本格式，不是 Python 字典的别名；JSON 对象、数组通常分别解析成 `dict`、`list`。
`json` 是标准库，负责 JSON 编解码，不发送请求；`json.dumps` 把 Python 对象序列化成字符串。
`indent=2` 只改善缩进显示，`ensure_ascii=False` 允许直接显示中文；两者都不改变字段含义。
这里 `data["results"]` 是列表，循环每次拿到一个歌曲字典，再由 `result["trackName"]` 取得标题。
服务若返回空列表，循环执行零次；字段缺失可能导致 `KeyError`，要先检查真实响应，不能猜字段路径。
追踪一次：用户参数 → 查询字符串 → HTTP 响应 → Python 字典 → 结果列表 → 单条标题。
先把 `limit` 设为 1 便于观察，再改成 50；数量是上限，不保证一定填满。
本章补充了参数编码、超时和错误状态检查；依据 [Requests 官方 Quickstart](https://requests.readthedocs.io/en/latest/user/quickstart/)。
该外部服务未在本文编写时实测；访问限制、响应内容和接口约定可能变化，不能把示例当成离线必成功程序。

## 8. Making Your Own Libraries：两个文件与入口保护

双文件例子，先创建 `sayings.py`：

```python
def hello(name):
    print(f"hello, {name}")


def goodbye(name):
    print(f"goodbye, {name}")


def main():
    hello("world")
    goodbye("world")


if __name__ == "__main__":
    main()
```

再将同目录的 `say.py` 替换为以下内容；这次不再依赖 `cowsay`：

```python
import sys

from sayings import goodbye

if len(sys.argv) != 2:
    sys.exit("Usage: python say.py NAME")

goodbye(sys.argv[1])
```

`sayings` 是项目内模块，不需要 `pip install`；`goodbye` 是你定义的普通函数。
运行 `python sayings.py` 会输出两句；运行 `python say.py David` 只应输出 `goodbye, David`。
`__name__` 是解释器提供的模块变量：直接运行文件时通常为 `"__main__"`，导入此文件时为 `"sayings"`。
`if` 是入口保护，不是装饰器；`main` 也不是关键字，只是约定的函数名。
首次导入通常执行模块顶层语句来建立定义；如果顶层无条件调用 `main()`，导入时也会问候。
入口保护只拦住条件内的调用，不会禁止其余顶层语句执行。详见 [Python 模块教程](https://docs.python.org/3/tutorial/modules.html)。

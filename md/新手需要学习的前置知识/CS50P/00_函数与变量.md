# 00. 函数与变量

> 心智模型：程序接收输入，把值交给函数处理，再把结果返回给调用处或显示出来。

## 起点、环境与边界

先能找到终端、保存 `.py` 文件，并区分终端命令和文件里的 Python 代码。
本章从官方的问候程序走到计算器、自定义函数，完整学习第 0 单元，不按后续项目筛选。
本章不要求掌握条件分支、异常处理、类或模块导入；这些会在后续单元出现。
所有 Python 代码块都是独立的完整程序；同名文件的不同版本要分别运行，不要直接拼接。
在自己已经激活的 Python 环境中，进入练习文件所在目录，用下面的命令运行：

```bash
python hello.py
```

`hello.py` 是你保存的练习文件名，不是本仓库预先提供的示例文件。
激活环境后统一使用 `python`，它应指向该环境的解释器；不需要安装第三方包。
也可以在终端运行 `python` 进入交互模式，看到 `>>>` 后输入表达式，例如 `1 + 1`。
`>>>` 是解释器提示符，不写进文件；输入 `exit()` 退出后再运行文件命令。
下面的输入输出是学习时的预期现象，不等于你已在本机完成验证。

## 1. 创建代码：从函数调用开始

将下面的程序放入 `hello.py`，运行后应看到一行 `hello, world`。

```python
print("hello, world")
```

`print` 是 Python 内置函数，不需要 `import`；括号表示调用，字符串是传给它的实参。
调用者是文件顶层代码，输入是文字，效果是写到终端；这种可观察的外部影响叫副作用。
`print` 还会返回 `None`，表示没有有用的返回结果，不是把显示的文字返回给你。
函数可以同时具有返回值和副作用，不能把“有输出”一律理解成“有返回值”。
双引号内的 `hello, world` 是字符串字面量，表示一段 `str` 类型的文本值。

如果漏掉结束引号或右括号，解释器会报告语法错误，而不是自动补全程序。
先读报错末尾、文件名和行号，检查括号、引号；更完整的分类与恢复在第 3 单元学习。
能运行但结果不符合预期也是 bug，例如把问候写成固定的 `hello, name`。

## 2. 输入、返回值与变量

```python
name = input("What's your name? ")
print("hello,", name)
```

输入 `David` 后应显示 `hello, David`。
`input` 是内置函数：显示提示，等待用户提交一行文字，返回不含末尾换行符的字符串。
输入 `123` 也会返回字符串 `"123"`，不会自动判断成整数。
`name = ...` 是赋值：先计算右侧，再让左侧的名字绑定到得到的值。
变量不是引号里的文字，`print("name")` 和 `print(name)` 的含义不同。

追踪一次输入 `David` 的执行过程：

| 顺序 | 谁做什么 | 结果去哪里 |
| --- | --- | --- |
| 1 | 顶层代码调用 `input`，传入提示文本 | 终端显示提示 |
| 2 | 用户输入并按回车 | `input` 返回 `"David"` |
| 3 | 执行赋值 | `name` 绑定字符串 |
| 4 | 调用 `print`，传入两个实参 | 终端显示问候 |

变量绑定可以改变，字符串值本身不会因为换了变量名而改变。
变量名用有意义的小写名称；多个单词用下划线，例如 `first_name`。

## 3. 注释、伪代码与可读性

```python
# Keep the greeting separate from the user's input.
name = input("What's your name? ")
print("hello,", name)
```

`#` 后面的内容是注释，不作为语句执行；它说明意图，不负责替程序做事。
写程序前可以先用自然语言列步骤，这叫伪代码，不是 Python 语法：

```text
询问姓名
记住输入
输出问候和姓名
```

再把每一步落实成真实代码。注释和伪代码能帮助设计，但不能代替实现。
官方强调可读性：不必为了少一行而把多次处理全部塞进一个难读的表达式。

## 4. 多个实参、默认参数与字符串引号

```python
name = "David"
print("hello, " + name)
print("hello,", name, sep=" ")
print("hello, ", end="")
print(name)
print('hello, "friend"')
print("hello, \"friend\"")
```

前四次 `print` 调用总共产生三行相同的问候，最后两行都带有双引号。
`+` 在两个字符串之间表示拼接；`print` 接收多个实参则会分别格式化它们。
`sep` 和 `end` 是 `print` 的参数，调用时用名字提供值，称为关键字实参。
`sep` 默认是一个空格，放在多个输出对象之间；`end` 默认是换行符 `\n`。
`end=""` 让下一次输出接在当前行，空字符串不等于空格。
形参是函数定义中接收值的名字；实参是调用时提供的实际值，二者不要混称。
没有显式给出的可选参数会采用默认值，不表示函数没有这些参数。
单引号和双引号都可界定字符串；外层与内层错开，或用 `\"` 转义双引号。
这里的反斜杠参与源代码解释，输出中不会额外出现一个反斜杠。

## 5. f-string：把值放进文本

```python
name = "David"
print(f"hello, {name}")
print("hello, {name}")
```

第一行问候含 `David`，第二行保留字面的 `{name}`。
`f"..."` 是格式化字符串字面量，简称 f-string，不是一个新函数。
Python 计算花括号里的表达式，把结果格式化后组成一个新的字符串，之后才调用 `print`。
它适合把变量嵌入一段文字；多个简单对象的输出仍可以直接用 `print(a, b)`。

## 6. 字符串方法：清理，再使用

```python
name = input("What's your name? ")
name = name.strip()
name = name.title()
print(f"hello, {name}")
```

输入两侧带空格的 `  david malan  `，预期显示 `hello, David Malan`。
`name` 指向字符串对象，`.strip()` 和 `.title()` 是这个对象提供的方法调用。
它们不需要导入，也不是你用 `def` 定义的普通顶层函数。
`strip()` 返回去掉两端空白的字符串，不会删掉中间的空格。
`title()` 返回按其大小写规则处理的字符串，不是可靠的人名规范化算法。
字符串不可变：这些方法返回新结果，不会原地修改原字符串，所以这里要接住返回值。

```python
raw_name = "  david malan  "
clean_name = raw_name.strip().title()
print(f"[{raw_name}]")
print(f"[{clean_name}]")
print(clean_name.capitalize())
```

方括号帮助观察空白：第一行仍有首尾空格，第二行没有。
链式调用先执行 `strip()`，再对它返回的字符串执行 `title()`。
第三行显示 `David malan`：`capitalize()` 处理整段文字的开头，并把其余部分转为小写。
`title()` 则按单词边界处理大小写，所以得到 `David Malan`；两者不能互换。
这里只要求把方法理解成“某个对象提供的可调用操作”，类的实现留到第 8 单元。

### 拆分姓名，再解包到两个变量

```python
name = input("What's your name? ").strip().title()
first, last = name.split(" ")
print(f"hello, {first}")
print(f"family name: {last}")
```

输入 `david malan`，应显示 `hello, David` 与 `family name: Malan`。
`split(" ")` 是字符串方法：调用者提供分隔符，一个普通空格；返回拆开的字符串列表。
列表是按顺序装多个值的容器，第 2 单元会展开；这里返回 `['David', 'Malan']`。
`first, last = ...` 是解包赋值：依次把右侧的两个元素交给左侧的两个变量。
不是由 Python 识别人类姓名，而是程序约定“恰好两部分，前一部分作名，后一部分作姓”。
只输入 `David` 或输入 `David John Malan`，元素数量与两个变量不一致，会抛出 `ValueError`。
多个连续空格还会产生空字符串；`strip()` 只清两端，不能消除中间的连续空格。
不传分隔符的 `name.split()` 按连续空白拆分并忽略两端空白，但仍不保证只有两部分。
先用恰好两部分验证调用链，再尝试上述反例；真实姓名不能一概假定都是两段。
这是课堂字符串操作的必要机制，异常恢复留到第 3 单元，不在这里用猜测掩盖限制。

## 7. 整数、类型转换与运算符

```python
x_text = input("What's x? ")
y_text = input("What's y? ")
print(x_text + y_text)
x = int(x_text)
y = int(y_text)
print(x + y)
```

依次输入 `1`、`2`，先得到 `12`，再得到 `3`。
`str` 和 `int` 是内置类型，准确说是类；`int("1")` 的调用创建一个整数结果。
这里通常称为类型转换；原来的 `x_text` 仍绑定字符串，没有被临时“变成”整数。
在 `int(input("What's x? "))` 中先执行内层 `input`，再把其返回值交给 `int`。
`int("1.5")`、`int("hello")` 无法解析整数文本，会抛出 `ValueError`，第 3 单元处理。

```python
x = 7
y = 2
print(x + y)
print(x - y)
print(x * y)
print(x / y)
print(x % y)
print(x ** 2)
```

依次输出 `9`、`5`、`14`、`3.5`、`1`、`49`。
`+ - * /` 分别是加减乘除，`%` 是取模，`**` 是乘方。
两个整数相除，`/` 的结果也通常是 `float`，不是截断成整数；除数不能为零。
本章先识别 `%`，下一章用它判定奇偶；括号可以明确表达式的运算顺序。

## 8. 浮点数、round 与输出格式

```python
x = float(input("What's x? "))
y = float(input("What's y? "))
total = x + y
print(total)
print(round(total))
print(f"{round(total):,}")
```

输入 `1000.2`、`500.4`，预期看到约 `1500.6`、`1501` 和 `1,501`。
`float` 是内置浮点类型，适合表示许多含小数的数量，但不是任意精度实数。
普通浮点数用有限的二进制位近似表示，十进制输入可能无法精确存储。
`round` 是内置函数，接收数字，返回舍入结果；省略第二实参时，对普通浮点数返回整数。
`: ,` 去掉中间空格写作 `:,`，是 f-string 的千位分组格式，不会改变数值本身。

```python
x = 2
y = 3
quotient = x / y
print(quotient)
print(round(quotient, 2))
print(f"{quotient:.2f}")
print(round(2.5), round(3.5))
print(f"{2.0:.2f}")
```

前三行预期为 `0.6666666666666666`、`0.67`、`0.67`。
`round(number, 2)` 返回舍入后的数字；`:.2f` 则生成固定两位小数的显示文本。
最后一行显示 `2.00`，说明格式化可以补零，并不意味着原值更精确。
不要把 `round` 简化为小学“四舍五入”：恰好处于中间时取最接近的偶数，例中为 `2 4`。
浮点近似还会影响所谓“恰好中间”；精确金额计算是后续话题，不能靠显示两位解决。
这些边界参见 [Python 内置函数文档](https://docs.python.org/3/library/functions.html#round)。

## 9. def：定义可复用的函数

```python
def hello(to="world"):
    print(f"hello, {to}")


name = input("What's your name? ").strip().title()
hello(name)
hello()
```

`def` 是定义函数的关键字，执行定义时创建函数对象并把它绑定到 `hello`。
定义不是调用；只有运行到 `hello(name)` 才进入缩进的函数体。
冒号开启代码块，块内统一缩进四个空格；缩进是语法，不只是排版。
`to` 是形参；调用者传入 `name` 当前的值，函数内部用 `to` 访问它。
第二次没有提供实参，因此使用默认值 `"world"`；默认值不限制以后只能传这个值。
调用前必须已经执行对应定义；不能在顶层先调用一个尚未定义的 `hello`。

## 10. main 与作用域

```python
def main():
    name = input("What's your name? ").strip()
    hello(name)


def hello(to="world"):
    print(f"hello, {to}")


main()
```

顶层先定义 `main`，再定义 `hello`，最后调用 `main()`，所以进入 `main` 时 `hello` 已存在。
`main` 是我们约定的普通函数名，不是关键字，Python 不会因为这个名字就自动运行它。
`name` 是 `main` 的局部变量；`to` 是 `hello` 的局部参数。
作用域是名字可以被查找的范围。`hello` 不会自动看到调用者 `main` 的局部 `name`。
传参数是在函数边界明确交接值，不要依赖“两个函数里写了同一个变量名”。
如果在函数外直接使用上述局部 `name`，会找不到它；不要用增加全局变量来掩盖边界。

## 11. return：把计算结果交还调用处

```python
def main():
    x = int(input("What's x? "))
    result = square(x)
    print("x squared is", result)


def square(n):
    return n * n


main()
```

输入 `4`，调用链为：`main` 得到整数 → `square(4)` 中 `n` 绑定 `4` → 返回 `16` → `result` 接住。
`return` 立即结束当前函数调用，把值交还调用处；不是向终端输出。
若把 `return n * n` 改成 `print(n * n)`，函数会显示 `16`，但 `result` 得到 `None`。
没有执行带值的 `return` 而自然结束的普通函数，默认返回 `None`。
这就是“函数做计算”和“调用者决定如何展示”分开的好处。

## 12. 入口保护：提前认识，后面解释模块

```python
def main():
    print("x squared is", square(4))


def square(n):
    return n ** 2


if __name__ == "__main__":
    main()
```

这是在本单元函数例子上补充的前瞻写法，不是官方第 0 单元笔记已完整讲授的机制。
直接运行 `python calculator.py` 时，解释器设置 `__name__` 为 `"__main__"`，条件成立才调用 `main`。
第 1 单元讲 `if` 与 `==`，第 4 单元讲模块：文件被导入时通常不会通过这个入口条件。
现在能识别“定义函数”和“启动程序”的区别即可；前面的直接 `main()` 版本仍是有效程序。

## 1. 从过程式程序到元组、列表与字典（student.py）

```python
def get_student():
    name = input("Name: ")
    house = input("House: ")
    return name, house


def main():
    name, house = get_student()
    print(f"{name} from {house}")


if __name__ == "__main__":
    main()
```

`main` 调用普通函数 `get_student`，采集两个字符串并返回元组，再由调用者解包。`return name, house` 的逗号把两项打包成一个 `tuple` 对象。
元组是有顺序的不可变序列：不能把已有元组的某个槽位重新赋值；并不保证其中引用的可变对象也不可变。
为什么还要继续改？`student[1]` 要依赖位置约定，而以后可能需要修正学生学院。

```python
student_tuple = ("Padma", "Gryffindor")
print(student_tuple[0], student_tuple[1])
student_list = ["Padma", "Gryffindor"]
student_list[1] = "Ravenclaw"
student_dict = {"name": "Padma", "house": "Gryffindor"}
student_dict["house"] = "Ravenclaw"
print(student_list)
print(f"{student_dict['name']} from {student_dict['house']}")
```

列表可修改槽位；字典可用字段名读写。给 `student_tuple[1]` 赋值会发生 `TypeError`，但变量名仍可重新绑定到另一个元组。
字典适合简单记录，却不自动限制字段或检查学院。类不是它的“高级替代品”，而是让数据与行为共同维护约束的选择。

## 2. 类、实例与初始化

```python
class Student:
    def __init__(self, name, house):
        self.name = name
        self.house = house


harry = Student("Harry", "Gryffindor")
hermione = Student("Hermione", "Gryffindor")
print(harry.name, harry.house)
print(hermione.name)
```

`class Student` 创建类对象，即自定义类型，类名通常首字母大写。调用 `Student(...)` 构造实例（instance），结果绑定到 `harry`；`hermione` 是另一个实例。
属性（attribute）用点号访问；`self.name`、`self.house` 保存实例状态。`name` 只是局部参数，与 `self.name` 不在同一名字空间。

追踪构造：`Student(...)` → 创建实例 → 调用 `__init__` 初始化 → 类调用返回实例。`__init__` 是初始化方法，不负责返回新对象，必须返回 `None`。
`self` 是惯例命名的首个参数，指向当前实例，不是关键字。用户只给 `name, house`，构造流程负责提供 `self`。
修改 `harry.house` 不会同步修改 `hermione.house`，因为这里写的是不同实例上的属性。

## 3. raise：让不合法的对象无法正常构造

```python
class Student:
    def __init__(self, name, house):
        if not name.strip():
            raise ValueError("Missing name")
        if house not in ["Gryffindor", "Hufflepuff", "Ravenclaw", "Slytherin"]:
            raise ValueError("Invalid house")
        self.name = name
        self.house = house


try:
    student = Student("Harry", "Privet Drive")
except ValueError as error:
    print(error)
```

输出 `Invalid house`；`raise` 是语句，`ValueError` 是内置异常类，调用它创建异常对象。抛出后初始化中断，沿调用链寻找 `except`，此次赋值不会正常得到新实例。
“参数类型合适但值不符合约定”适合 `ValueError`；不要用 `print` 警告后还继续返回一个看似成功的对象。
此类假定 `name` 是字符串，写类不会自动添加类型检查。类负责自身规则，调用者决定呈现或重试，不应在每个方法里直接终止程序。

## 4. __str__ 与实例方法

官方继续添加可读描述和守护神行为，完整 `student.py`：
```python
class Student:
    def __init__(self, name, house, patronus=None):
        if not name:
            raise ValueError("Missing name")
        if house not in ["Gryffindor", "Hufflepuff", "Ravenclaw", "Slytherin"]:
            raise ValueError("Invalid house")
        self.name = name
        self.house = house
        self.patronus = patronus

    def __str__(self):
        return f"{self.name} from {self.house}"

    def charm(self):
        forms = {"Stag": "stag", "Otter": "otter"}
        return forms.get(self.patronus, "unknown patronus")


student = Student("Harry", "Gryffindor", "Stag")
print(student)
print(student.charm())
```

输出 `Harry from Gryffindor` 和 `stag`，用文本表示课堂守护神形象。特殊方法 `__str__` 供 `str(student)`、`print(student)` 的转换使用，必须返回字符串，不能只打印。
若没有自定义它，通常得到包含类型和地址信息的默认描述，而不是自动列出所有字段。
`charm` 是自定义实例方法；`student.charm()` 隐含输入当前实例，返回字符串。按普通方法绑定规则，可理解为 `Student.charm(student)`，点号调用负责传入 `self`。
`dict.get(key, default)` 返回已有值或默认值，不修改 `forms`，也不验证所有守护神。`patronus=None` 表示省略时存储 `None`，不是属性不存在。

## 5. 属性与装饰器：构造之后也守住规则

仅初始化校验不够：之后普通属性仍接受 `student.house = "Privet Drive"`。看完整 `property` 版本如何拦截赋值：

```python
class Student:
    def __init__(self, name, house):
        self.name = name
        self.house = house

    def __str__(self):
        return f"{self.name} from {self.house}"

    @property
    def name(self):
        return self._name

    @name.setter
    def name(self, value):
        if not value.strip():
            raise ValueError("Missing name")
        self._name = value

    @property
    def house(self):
        return self._house

    @house.setter
    def house(self, value):
        if value not in ["Gryffindor", "Hufflepuff", "Ravenclaw", "Slytherin"]:
            raise ValueError("Invalid house")
        self._house = value


student = Student("Harry", "Gryffindor")
try:
    student.house = "Privet Drive"
except ValueError as error:
    print(error)
print(student)
```

先打印 `Invalid house` 再打印原描述，失败赋值未覆盖旧值。`property` 是内置类，`@property` 是装饰器语法，类定义时把读取函数包装成 property 对象。
装饰器在定义时接收对象并产生替代对象，不等于“每次调用前打印日志”。`@house.setter` 使用已有 property 的接口加入写入函数。
读 `student.house` 触发 getter 返回 `_house`，写入则触发 setter 校验后更新 `_house`；初始化里的 `self.house = house` 也走 setter，共用同一校验。
setter 内不能再写 `self.house = value`，否则重复触发自己直到递归错误；真正存储使用 `_house`。

`_house` 的单下划线只是内部使用约定。外部仍能改 `student._house` 绕过 setter；property 约束公开接口，不是防御恶意代码的隐私或安全屏障。
双下划线 `__house` 会进行名称改写以减少子类冲突，也不是不可访问的秘密存储。
只写 getter 不写 setter，可以让这个公开属性拒绝普通赋值；并不保证对象内部从此不可变。

## 6. 连接旧知识：内置类型一直也是类

```python
number = int("50")
name = str(" Harry ")
names = list()
names.append(name.strip().lower())
student = dict(name=names[0], house="Gryffindor")
print(type(number), type(name), type(names), type(student))
print(student)
```

`int`、`str`、`list`、`dict` 是内置类，字面量也产生相应实例。`strip/lower` 是返回新字符串的实例方法；`append` 修改列表并返回 `None`。
`type(value)` 返回对象类型，帮你把旧的点号调用与实例方法联系起来；这不要求以后全写成类，简单变换仍可用普通函数。

## 7. 类变量与类方法

官方分院帽例子把分院操作移到类上，独立运行 `hat.py`：
```python
import random


class Hat:
    houses = ("Gryffindor", "Hufflepuff", "Ravenclaw", "Slytherin")

    @classmethod
    def sort(cls, name):
        return f"{name} is in {random.choice(cls.houses)}"


print(Hat.sort("Harry"))
```

`random` 是标准库模块，`choice` 从非空序列随机选一项，不是密码学随机源。类体中的 `houses` 是类属性，用元组表示不需修改的选项。
类属性由通过类访问的调用共享，不等同于 `__init__` 中每次创建的实例属性；可变列表类属性尤其要小心共同修改。
内置装饰器 `classmethod` 让 `Hat.sort("Harry")` 自动把类传给 `cls`，用户只传名字，无需先 `Hat()`；经实例访问类方法时也绑定到类。

再看类方法作为替代构造入口，独立的简化 `student.py`：

```python
class Student:
    def __init__(self, name, house):
        self.name = name
        self.house = house

    @classmethod
    def get(cls):
        name = input("Name: ")
        house = input("House: ")
        return cls(name, house)


student = Student.get()
print(student.name, student.house)
```

调用链：`Student.get()` → `cls` 绑定类 → 输入 → `cls(name, house)` → 初始化 → 返回实例。这个简化版只隔离构造入口，整合时可保留 property 校验。
写 `cls(...)` 而非固定 `Student(...)`，让继承后的类方法也有机会构造调用它的子类。

## 8. 静态方法：不自动收到 self 或 cls

官方列出静态方法并邀请课外探索；这里补一个可运行对照，不展开装饰器底层实现：

```python
class Student:
    @staticmethod
    def valid_house(house):
        return house in ("Gryffindor", "Hufflepuff", "Ravenclaw", "Slytherin")


print(Student.valid_house("Ravenclaw"))
```

内置装饰器 `staticmethod` 使调用只接收显式的 `house`，返回布尔值。实例方法操作实例状态，类方法用于类级操作或替代构造，静态方法是类名字空间下的相关工具。
如果工具与这个类没有紧密关系，模块级普通函数更自然；不是“写在类里就更专业”。

## 9. 继承与 super（wizard.py）

```python
class Wizard:
    def __init__(self, name):
        if not name:
            raise ValueError("Missing name")
        self.name = name


class Student(Wizard):
    def __init__(self, name, house):
        super().__init__(name)
        self.house = house


class Professor(Wizard):
    def __init__(self, name, subject):
        super().__init__(name)
        self.subject = subject


student = Student("Harry", "Gryffindor")
professor = Professor("Severus", "Defense Against the Dark Arts")
print(student.name, professor.name)
print(isinstance(student, Student), isinstance(student, Wizard))
```

`Student(Wizard)` 声明继承：子类可复用或覆盖基类方法。内置类 `super` 的调用返回沿方法解析顺序继续查找的代理，本例中找到 `Wizard.__init__`。
这不另建父对象，而是在同一实例上先写 `name` 再写 `house`。子类定义了 `__init__` 后，基类初始化不会自动额外执行，需要显式调用。
最后两项都是 `True`；内置 `isinstance` 检查对象是否属于该类型或子类型。继承应表达“是一种”，本例尚未添加学院和科目验证。

## 10. 异常也是继承层次

```python
try:
    int("Harry")
except ValueError:
    print("Specific invalid value")
except Exception:
    print("Other ordinary exception")
```

输出第一条：捕获基类异常也能捕获它的子类，所以更具体的处理通常放在前面。
`ValueError`、`ArithmeticError`、`LookupError` 继承自 `Exception`，`ZeroDivisionError` 继承自 `ArithmeticError`；顶层是 `BaseException`，`KeyboardInterrupt/SystemExit` 不属于普通 `Exception` 分支。
`except Exception` 通常不吞掉用户中断；不要随意捕获 `BaseException`。自定义普通业务异常通常也继承 `Exception` 或其适当子类。

## 11. 运算符重载：金库相加（vault.py）

```python
class Vault:
    def __init__(self, galleons=0, sickles=0, knuts=0):
        self.galleons = galleons
        self.sickles = sickles
        self.knuts = knuts

    def __str__(self):
        return f"{self.galleons} Galleons, {self.sickles} Sickles, {self.knuts} Knuts"

    def __add__(self, other):
        if not isinstance(other, Vault):
            return NotImplemented
        return Vault(self.galleons + other.galleons,
                     self.sickles + other.sickles,
                     self.knuts + other.knuts)


potter = Vault(100, 50, 25)
weasley = Vault(25, 50, 100)
total = potter + weasley
print(total)
print(potter)
```

第一行是 `125 Galleons, 100 Sickles, 125 Knuts`，第二行仍是原值。`potter + weasley` 使用 `__add__`，左侧进入 `self`，右侧进入 `other`，返回新 `Vault`。
`NotImplemented` 是内置特殊值，让 Python 尝试其他路径，最终不支持时产生 `TypeError`；不要写 `raise NotImplemented`，它不是 `NotImplementedError` 异常。
这里按币种逐项相加，没有执行进位或汇率归一化，也没有自动改变左右两个金库。

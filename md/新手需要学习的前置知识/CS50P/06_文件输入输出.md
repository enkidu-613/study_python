## 1. File I/O：名单先在内存里

创建 `names_memory.py`：

```python
names = []
for _ in range(3):
    names.append(input("What's your name? "))

for name in sorted(names):
    print(f"hello, {name}")
```

运行 `python names_memory.py`，依次输入 Ron、Harry、Hermione，问候顺序应为 Harry、Hermione、Ron。
`append` 是列表方法，接收一个元素并修改列表；`sorted` 是内置函数，接收可迭代数据，返回新的排序列表。
这里排序不修改 `names`；默认字符串比较也不是按中文拼音排序，大小写可能影响顺序。
程序结束后，这个列表不会自动保留；下次启动又是空列表。
**文件 I/O（输入/输出）**指从文件读取数据或向文件写出数据，不等于只用 `input`、`print`。

## 2. open：模式决定是读、覆盖还是追加

创建 `names_write.py`，只在练习目录运行：

```python
name = input("What's your name? ")
file = open("names.txt", "w", encoding="utf-8")
file.write(name + "\n")
file.close()
```

`open` 是内置函数，输入路径、模式和文本编码，返回文件对象；`file` 不是文件名字符串。
`file.write` 是方法，输入字符串，把它写入文件流，返回写入的字符数；它不会自动添加换行。
`file.close` 关闭文件并刷新缓冲；尚未关闭不等于数据一定已经完整写到磁盘可见的位置。
这里用 UTF-8 明确中文的编码，避免不同系统默认编码带来差异。

| 模式 | 已存在文件 | 不存在文件 | 本章用途 |
| --- | --- | --- | --- |
| `"r"` | 从头读取 | 抛出 `FileNotFoundError` | 读名单；省略模式时默认它 |
| `"w"` | 打开时就截断原内容 | 创建文件 | 重建练习输出 |
| `"a"` | 在末尾追加 | 创建文件 | 累积姓名 |

先输入 Harry 运行一次，再输入 Ron 运行一次；`"w"` 版本最终只留下 Ron 那一行。
将模式改为 `"a"` 后再运行，应在末尾加一行；若不写 `"\n"`，两次姓名会粘在一起。
`\n` 是字符串中的换行字符，不是两个要原样写出的反斜杠和字母。
手写 `close` 的局限是中途异常可能让执行越过关闭动作，下面用 `with` 管理资源。

## 3. with：把关闭责任交给上下文

创建 `names_append.py`：

```python
name = input("What's your name? ")
with open("names.txt", "a", encoding="utf-8") as file:
    file.write(f"{name}\n")
```

`with` 是语句，`open` 产生支持上下文管理协议的文件对象，`as file` 将其交给块内代码使用。
离开缩进块时，文件会关闭，即使块内因异常退出也会进行清理；但不表示异常被自动消除。
关闭后不要再调用该文件对象的读写方法；不要为了继续使用它而把循环放到错误的缩进层级。
这里管理的是资源的生命周期，而上一章 `pytest.raises` 管理的是预期异常检查范围。

### readlines：一次读出全部行

创建 `names_read.py`，前提是刚才已经生成 `names.txt`：

```python
with open("names.txt", "r", encoding="utf-8") as file:
    lines = file.readlines()

for line in lines:
    print("hello,", line.rstrip())
```

`readlines()` 是文件方法，无参数时从当前位置读取剩余所有行，返回字符串列表。
行通常保留结尾的换行；`print` 默认又添换行，直接打印便可能出现空白行。
`rstrip()` 是字符串方法，返回去掉尾部空白的新字符串，不修改原字符串；它不只去掉换行。
如果尾随空格有意义，可改成 `rstrip("\n")`，只去掉末尾的换行字符。
文件已关闭，但 `lines` 是内存里的列表，仍可在 `with` 外使用。

### 直接迭代文件，再决定是否排序

不必总把所有行存入列表；`names_stream.py`：

```python
with open("names.txt", encoding="utf-8") as file:
    for line in file:
        print("hello,", line.rstrip("\n"))
```

`for` 从文件对象逐行取得字符串；文件大时，这比先 `readlines()` 更节省内存。
若要全局排序，必须收集待比较的数据；创建 `names_sorted.py`：

```python
names = []
with open("names.txt", encoding="utf-8") as file:
    for line in file:
        names.append(line.rstrip("\n"))

for name in sorted(names, reverse=True):
    print(f"hello, {name}")
```

先去掉尾部换行再排序，`reverse=True` 改为逆序；去掉它恢复默认顺序。
也可在 `with` 内遍历 `sorted(file)`，但那仍会收集全部行，并非流式排序。
数据文件不存在时检查目录和前置写入步骤；权限错误应检查授权，不能靠换个应用绕过。

## 4. CSV：一行不止一个字段

先创建无表头的练习数据 `students.csv`：

```csv
Hermione,Gryffindor
Harry,Gryffindor
Ron,Gryffindor
Draco,Slytherin
```

再创建 `students_split.py`，本段仅适用于每行恰有一个逗号的受限数据：

```python
students = []
with open("students.csv", encoding="utf-8") as file:
    for line in file:
        name, house = line.rstrip("\n").split(",")
        students.append({"name": name, "house": house})


def get_name(student):
    return student["name"]


for student in sorted(students, key=get_name):
    print(f"{student['name']} is in {student['house']}")
```

CSV 是逗号分隔值格式；`split(",")` 返回字符串列表，左边两个变量通过**解包**分别接收两个元素。
它不是“返回两个独立值”；如果行里多一个逗号，元素变成三个，解包就会抛 `ValueError`。
字典把字段名与值配对；列表保存多条字典记录，方便稍后按姓名而非按整行文本排序。
不能直接假设 `sorted(students)` 知道怎样比较两个字典；需要提供排序键。

### key 与 lambda：把函数交给 sorted 调用

上面 `key=get_name` 传的是函数对象，不是 `get_name()` 的执行结果。
`sorted` 会用每个学生字典调用它，以返回的姓名字符串作排序依据；返回的列表元素仍是完整字典。
如果只使用一次，也可以写成下面这个独立小实验 `student_order.py`：

```python
students = [
    {"name": "Ron", "house": "Gryffindor"},
    {"name": "Harry", "house": "Gryffindor"},
]
for student in sorted(students, key=lambda student: student["name"]):
    print(student["name"])
```

`lambda student: student["name"]` 创建匿名函数，接收一条记录，返回该记录的姓名；不是字符串，也不是字典的一个键。
这里的 `student` 是形参，由 `sorted` 传入；循环目标中的同名变量则在循环取到元素时绑定。
把排序键改为 `student["house"]` 可按学院排，但学院相同时会保留原有相对次序。
多步骤逻辑用 `def` 更清楚，不需要为了“高级”而强行用 lambda。

### split 的边界：引号中的逗号不是分隔符

另存无表头的 `homes.csv`：

```csv
Harry,"Number Four, Privet Drive"
Ron,The Burrow
Draco,Malfoy Manor
```

对第一行直接 `split(",")` 会得到三个片段，它不懂 CSV 的引号规则；`split(",", 1)` 也不是通用 CSV 解析器。
应由标准库 `csv` 处理字段引用、分隔符等规则，不能靠不断给字符串切分打补丁。

创建 `students_reader.py`，读取上面的 `homes.csv`：

```python
import csv

students = []
with open("homes.csv", encoding="utf-8", newline="") as file:
    reader = csv.reader(file)
    for row in reader:
        students.append({"name": row[0], "home": row[1]})

for student in sorted(students, key=lambda student: student["name"]):
    print(f"{student['name']} is from {student['home']}")
```

`csv` 是标准库，服务于表格文本的导入导出，不处理 Excel 工作簿格式或数据库查询。
`csv.reader` 是工厂函数，输入文件等字符串来源，返回 reader 对象；循环时每次产生一行字段列表。
第一行现在恰有两个字段，地址中的逗号保留在 `row[1]` 内；字段默认仍是字符串，不自动变数字。
`newline=""` 让 csv 模块自行处理换行，正确应对带换行的引号字段，也避免某些平台写出多余空行。
CSV 记录不一定等于一个物理文本行；字段内部也能含换行，这是逐行 `split` 的另一个限制。
解析器不代替业务校验：空行、列数错误或错误表头仍需按实际数据契约处理。

### DictReader：通过表头给字段命名

创建不同文件 `students_header.csv`，这次有表头：

```csv
name,home
Harry,"Number Four, Privet Drive"
Ron,The Burrow
Draco,Malfoy Manor
```

创建 `students_dictread.py`：

```python
import csv

students = []
with open("students_header.csv", encoding="utf-8", newline="") as file:
    reader = csv.DictReader(file)
    for row in reader:
        students.append({"name": row["name"], "home": row["home"]})

for student in sorted(students, key=lambda student: student["name"]):
    print(f"{student['name']} is from {student['home']}")
```

`csv.DictReader` 是类，创建出的实例默认用首条记录作字段名，后续每条记录生成字典。
因此不能忘记表头，否则第一个学生会变成字段名；`"name"` 与 `"Name"` 也不是同一个键。
将表头与对应数据列一起换序，按字段名读取仍可正常工作；按 `row[0]` 取姓名则依赖列的位置。

### writer 与 DictWriter：让库负责引用与转义

下面 `students_writer.py` 会重建练习输出 `students_out.csv`，不会覆盖输入：

```python
import csv

with open("students_out.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["name", "home"])
    writer.writerow(["Harry", "Number Four, Privet Drive"])
```

`csv.writer` 返回 writer 对象；其 `writerow` 方法接收一条字段序列，写出一条记录，必要时自动加引号。
它没有自动表头机制，这里是我们显式写入第一行；不要用字符串拼接代替字段序列。

如果手里已经是字典，使用 `students_dictwrite.py`：

```python
import csv

name = input("What's your name? ")
home = input("Where's your home? ")
with open("students_dict.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=["name", "home"])
    writer.writeheader()
    writer.writerow({"home": home, "name": name})
```

`csv.DictWriter` 是类；实例接收目标文件与列名顺序，`writeheader()` 才真正写表头，`writerow()` 根据列名取字典值。
这里字典书写顺序不同不影响输出列顺序。写完可将 `students_dictread.py` 的输入路径改为该文件验证。
若想累积多次输入，可改 `"a"` 追加，但必须约定何时首次建表头；不能每次追加都 `writeheader()`。
本章用每次重建的小文件把这两件事分开教，避免把重复表头混进数据。
上述行为与 `newline=""` 要求参照 [Python csv 官方文档](https://docs.python.org/3/library/csv.html)。

## 5. Binary Files and PIL：图像不是按行读的文本

下面是**额外运行条件**，不是删去的课程内容：需要第三方 Pillow 和至少两张本地图片。
仅在独立练习环境中、尚未安装时执行 `python -m pip install Pillow`；本文未执行安装，也不改项目依赖。
安装名是 `Pillow`，导入名沿用 `PIL`；它是图像读写与处理库，可处理头像、帧序列，不是视频剪辑或机器学习框架。
从[官方 Lecture 6 的图像示例](https://cs50.harvard.edu/python/notes/6/#binary-files-and-pil)取得 `costume1.gif` 与 `costume2.gif`，或使用自己有权使用的两张不同、同尺寸单帧图片。
把素材放在练习目录；这些图片不由本文自动生成，也不应假设已经存在于仓库。

创建 `costumes.py`：

```python
import sys

from PIL import Image

if len(sys.argv) < 3:
    sys.exit("Usage: python costumes.py FRAME1 FRAME2 [MORE_FRAMES]")

images = []
try:
    for filename in sys.argv[1:]:
        with Image.open(filename) as image:
            print(image.format, image.size)
            images.append(image.copy())
    images[0].save(
        "costumes.gif",
        save_all=True,
        append_images=images[1:],
        duration=200,
        loop=0,
    )
except (OSError, ValueError) as error:
    sys.exit(f"Image operation failed: {error}")
finally:
    for image in images:
        image.close()
```

运行 `python costumes.py costume1.gif costume2.gif`，预期打印输入格式和尺寸，并生成 `costumes.gif`；该输出名会覆盖同名文件。
`Image` 是从 `PIL` 包导入的模块；`Image.open` 是函数，输入路径，返回 `Image.Image` 实例或其子类实例。
文件格式、尺寸等属于图像对象属性；这里不把它误叫成普通文本文件对象。
`copy()` 产生独立图像副本，使帧数据能在输入文件的 `with` 结束后继续使用；最后关闭副本释放资源。
`images[0].save` 是实例方法：由第一帧启动输出，输入输出路径和编码参数，主要效果是写文件，不是返回新图像。
`save_all=True` 请求多帧保存，`append_images=images[1:]` 提供其余帧，`duration=200` 是每帧 200 毫秒，`loop=0` 表示无限循环。
这些是 GIF 保存参数，不是所有格式通用；修改为 `duration=500` 观察播放变慢，需用支持动画的查看器打开。
二进制文件同样是字节数据，文本也是字节编码；差异在解释规则，不能把 GIF 用 UTF-8 按行当姓名读。
本例按单帧输入演示；若输入本身是动画，并不会自动将其所有帧展开加入输出。
准确保存语义见 [Pillow GIF 文档](https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html#gif)；图片依赖与输出动画未在本文编写时实际验证。

# CS50P Final Project：自己的 Python 项目

> 原课程：David J. Malan 与 CS50 团队，Harvard University，[CS50P Final Project](https://cs50.harvard.edu/python/project/)。enkidu-613 根据官方要求整理中文说明，按 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 分享。[来源与许可](来源与许可.md)。

最终项目是你自己设计、实现并解释的 Python 程序。题材由你决定，课程要求你把各单元学到的能力用于一个比单次问题集更有工作量的作品。这里按官方要求准备项目，不再另设一份替代它的“学习待办结课题”。

## 官方实现要求

项目使用 Python；包含 `main` 函数与至少三个额外的自定义函数，其中至少三个额外函数配有可用 pytest 执行的测试。`main` 和这三个函数都定义在根目录的 `project.py` 中，并处于模块顶层：类方法或嵌套函数不能代替这个最低函数数量要求。

测试写在根目录 `test_project.py` 中，测试函数以 `test_` 加被测函数名命名。你可以在满足最低要求之后继续增加类、函数和模块。需要通过 pip 安装的依赖列入根目录 `requirements.txt`，每行一个。

```text
my_project/
  project.py
  test_project.py
  requirements.txt
  README.md
```

这个目录是你自己的最终项目根目录，不要求把当前 FastAPI 学习仓库改造成上述结构。先单独建立练习项目，避免将无关模型、数据库与应用配置一起带入。

## 先定功能，再写函数

先用几句话回答：谁使用它，输入什么，输出什么，哪些输入应被拒绝，怎样证明结果正确。题材可以是文件整理、文本分析、小型数据工具或命令行程序；先做你能独立解释的规模，再考虑增加界面或联网能力。

将处理逻辑与交互分开：`main` 负责组织流程，其他函数负责可测试的计算、解析或转换。只会打印、必须不停要求输入的函数不容易检查返回结果；你可以先让处理函数返回数据，再由 `main` 显示。

1. 先实现一条最小可用路径。
2. 为至少三个自定义函数编写正常、边界与错误输入的测试。
3. 使用真实输入运行程序，确认函数测试通过之外，整体流程也能完成。
4. 为代码、依赖、使用步骤和取舍补充 README。

在你自己的项目目录中，以下是开发阶段常用的运行方式；具体程序还可能需要参数或数据文件：

```bash
python project.py
python -m pytest test_project.py
```

## 官方提交包括什么

官方页面列出三个提交步骤：先准备不超过三分钟的项目演示视频并填写指定表单；再准备 README 和项目文件，按官方 `submit50` 指令提交；最后打开 Gradebook 检查评阅及课程完成情况。提交入口、命令、截止时间和视频信息要求可能变化，提交当天直接打开 [How to Submit](https://cs50.harvard.edu/python/project/#how-to-submit) 核对，不把这里的整理日期当成永久要求。

README 应说明项目用途、文件职责、运行方法及关键设计选择，并附演示链接。它应提供足够信息，让另一个人知道怎样运行并理解你的程序；官方也给出了篇幅与说明深度的建议。正式提交前同时核对[课程学术诚信规则](https://cs50.harvard.edu/python/honesty/)。

## 自查与下一步

- 能从头解释 `main` 怎样调用各函数，以及每个函数的输入、输出和错误路径。
- 至少三个额外顶层函数满足官方要求，并有相应测试。
- 在新虚拟环境里按依赖清单安装后能运行，测试能复现。
- README、演示与程序当前行为一致。

本地完成练习与官方评阅是两件事；需要证书时按官方流程完成问题集和最终项目。完成本课程的学习不要求先学习或完成下面列出的其他课程。

# 01. 条件判断

> 心智模型：先计算条件，再让程序只走符合条件的代码路径。

## 起点、环境与边界

先会用 `input`、`int`、`print`，知道赋值、形参、返回值和函数调用的区别。
本章沿官方的比较数字、成绩分档、奇偶函数和学院匹配，学习完整的分支机制。
不提前要求列表、循环、异常处理或结构化模式匹配的全部能力。
所有 Python 代码块均为独立完整程序；同名文件的版本分别运行。

```bash

```

无需安装第三方库。`match` 要求 Python 3.10 或更新版本，可用 `python --version` 检查。
后面的交互例子先假设用户输入可转换的整数；非法输入的恢复在第 3 单元学习。
文中的输入输出是预期检查标准，不代表你已在本机执行过。

## 1. 比较产生布尔值

```python
x = int(input("What's x? "))
y = int(input("What's y? "))
print(x < y)
print(x == y)
```

输入 `2`、`5`，应先显示 `True`，再显示 `False`。
`x < y` 是比较表达式，普通整数比较的结果是 `bool` 类型的值。
`True` 和 `False` 是两个布尔常量，首字母大写，不加引号。
`"False"` 则是非空字符串，不是布尔值 `False`。

| 写法 | 意义 | `x=2, y=5` 时 |
| --- | --- | --- |
| `x < y` | 小于 | `True` |
| `x > y` | 大于 | `False` |
| `x <= y` | 小于或等于 | `True` |
| `x >= y` | 大于或等于 | `False` |
| `x == y` | 值相等 | `False` |
| `x != y` | 值不相等 | `True` |

`=` 做赋值，`==` 做比较；判断相等不能少写一个等号。
本章主要比较整数和文字，不把大小比较推广到任意两种对象。
例如用户输入没有转成整数时，`"10" < "2"` 按字符串顺序比较，不是数值大小比较。

## 2. if：有条件地运行一个代码块

```python
x = int(input("What's x? "))
y = int(input("What's y? "))
if x < y:
    print("x is less than y")
print("Comparison finished")
```

`if` 是控制流关键字，不是函数；条件后的冒号与四空格缩进划出条件代码块。
顶层执行到 `if` 时，先计算比较；结果为真才进入块，为假则跳过。
最后一行不在缩进块里，无论条件真假都会运行。
输入 `2`、`5` 应显示两行；输入 `5`、`2` 只显示结束提示。

跟踪时不要只问“输出是什么”，还要指出哪一行被跳过、为什么。
控制流就是程序执行语句的路径，不是一个需要创建或导入的对象。

## 3. 多个 if 与 elif / else 不等价

```python
score = 95
if score >= 90:
    print("A")
if score >= 80:
    print("B")
```

这个程序显示两行，因为每个独立 `if` 都会检查自己的条件。
若目标是“只输出一个等级”，多个独立 `if` 就没有表达出互斥关系。

```python
x = int(input("What's x? "))
y = int(input("What's y? "))
if x < y:
    print("x is less than y")
elif x > y:
    print("x is greater than y")
else:
    print("x is equal to y")
```

`elif` 表示前面的条件都不成立时，再检查这一条件。
`else` 没有自己的条件，接住前面都不成立的情况；它不是“再检查一次相等”。
同一条 `if/elif/else` 链最多执行一个分支；命中后会跳过后续分支的条件检查。
三个比较对本章整数覆盖了小于、大于、等于，所以最后可以直接用 `else`。
`elif` 与 `else` 要和它对应的 `if` 对齐；缩进错位会改变含义或直接报错。

## 4. or：多个条件任一成立

```python
x = int(input("What's x? "))
y = int(input("What's y? "))
if x < y or x > y:
    print("x is not equal to y")
else:
    print("x is equal to y")
```

这里 `or` 连接两个完整比较；至少一个为真，整体条件就为真。
在普通整数比较中，也可以用 `x != y` 表达这个意图，代码更直接。
不要为了展示运算符而保留不必要的条件；选择最容易看懂的表达式。
`or` 会短路：若左侧已经为真，就不再计算右侧。
本章两侧都是比较表达式，所以整体结果是布尔值；一般的 `or` 并不保证返回 `bool`。

## 5. and：多个条件都成立

```python
score = int(input("Score: "))
if score >= 90 and score <= 100:
    print("Grade: A")
else:
    print("Not in the A interval")
```

`and` 要求两边都为真；左边为假时短路，不再计算右边。
这个例子判断的是闭区间 `[90, 100]`，端点 `90` 和 `100` 都包括在内。
Python 允许把相同意义的比较连写为 `90 <= score <= 100`。
连写是比较链，不是先算 `90 <= score` 后再把布尔值与 `100` 比较。

```python
score = int(input("Score: "))
if score < 0 or score > 100:
    print("Invalid score")
elif 90 <= score <= 100:
    print("Grade: A")
elif 80 <= score < 90:
    print("Grade: B")
elif 70 <= score < 80:
    print("Grade: C")
elif 60 <= score < 70:
    print("Grade: D")
else:
    print("Grade: F")
```

这里增加范围校验，避免把 `150` 当 A、把负数当 F。
先排除不合法范围，再做分档；这比假装所有用户都会输入合法分数更明确。
`0`、`59`、`60`、`69`、`70`、`79`、`80`、`89`、`90`、`100` 都值得检查。
测试边界的目的不是多跑几遍，而是确认每个区间没有空缺或重叠导致的错误。

## 6. 利用控制流，减少重复提问

```python
score = int(input("Score: "))
if score < 0 or score > 100:
    print("Invalid score")
elif score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
elif score >= 70:
    print("Grade: C")
elif score >= 60:
    print("Grade: D")
else:
    print("Grade: F")
```

到 `score >= 80` 这一行时，前面的 `score >= 90` 必定为假，因此不用重复写 `score < 90`。
这不是删除必要的校验，而是利用前面已经确定的事实。
顺序必须从高到低；若先写 `score >= 60`，95 就会提前落入这一档。
只有同一条 `elif` 链才提供这种保证，不能直接套用到多个独立 `if` 上。
自测：手算 `score=85` 时每个实际计算过的条件，再运行核对。

## 7. 取模与奇偶性

```python
x = int(input("What's x? "))
if x % 2 == 0:
    print("Even")
else:
    print("Odd")
```

`%` 是取模运算符，不是百分号或格式化标记；`x % 2` 得到除以 2 后的余数。
余数为零表示能被 2 整除，因此是偶数；普通整数还包括零和负整数。
尝试 `0`、`4`、`5`、`-4`、`-3`，不要只用正偶数验证。
这里除数始终为正数 2；不在本章扩展负除数的取模规则。
判断奇偶不用先算 `x / 2` 再检查小数，也不需要格式化成字符串。

## 8. 创建返回 bool 的函数

```python
def main():
    x = int(input("What's x? "))
    if is_even(x):
        print("Even")
    else:
        print("Odd")


def is_even(n):
    if n % 2 == 0:
        return True
    else:
        return False


if __name__ == "__main__":
    main()
```

`is_even` 是我们定义的普通函数，不是 Python 内置函数；调用前要执行它的定义。
调用者 `main` 提供整数 `x`，形参 `n` 接收值，返回结果供 `if` 决定分支。
`if is_even(x)` 已经在判断返回值，不必再写 `if is_even(x) == True`。
`return True` 不会显示文字；是 `main` 的分支决定显示 `Even` 或 `Odd`。
第一章前瞻的入口保护现在可以读成：名字相等时，才运行缩进的 `main()`。

## 9. 条件表达式与 Pythonic 简化

```python
def is_even(n):
    return True if n % 2 == 0 else False


number = 7
label = "Even" if is_even(number) else "Odd"
print(label)
```

`A if condition else B` 是条件表达式，产生一个值，先判断条件，再只计算选中的一侧。
它不是 `if/else` 语句的所有用法的替代品，尤其不适合把多步动作强挤成一行。
第一个函数还可以进一步简化，因为比较本身已经产生所需的布尔值：

```python
def is_even(n):
    return n % 2 == 0


print(is_even(8))
print(is_even(7))
```

预期输出 `True`、`False`。不要写成返回 `"True"` 和 `"False"`，那是两段非空文字。
Pythonic 指符合 Python 常见习惯、意图清楚的写法，不等于字符越少越好。
如果还不能解释简化前后的返回值为什么相同，先保留展开版本逐步追踪。

## 10. match：对离散值选择分支

```python
name = input("What's your name? ")
if name == "Harry" or name == "Hermione" or name == "Ron":
    print("Gryffindor")
elif name == "Draco":
    print("Slytherin")
else:
    print("Who?")
```

输入 `Harry` 或 `Ron` 走同一路径；每个 `or` 分支都必须写完整比较。
不能把它缩成 `name == "Harry" or "Ron"`：非空字符串本身为真，会导致错误的判定。
在本章场景中，`match` 能把“某些名字对应某个结果”的关系排列得更清楚。

```python
name = input("What's your name? ")
match name:
    case "Harry" | "Hermione" | "Ron":
        print("Gryffindor")
    case "Draco":
        print("Slytherin")
    case _:
        print("Who?")
```

`match` 是结构化模式匹配语句，本章只用字符串字面量模式、或模式和通配模式。
解释器把 `name` 的值依次与各个模式匹配，执行首个匹配的分支，不会继续贯穿后面的分支。
模式中的 `|` 表示备选模式；不要在这里写逻辑运算符 `or`。
`case _` 匹配未被前面接住的任意值，通常放最后，这里的 `_` 是通配符。
字符串模式带引号；随意写 `case Harry` 不是比较同名字符串，可能变成捕获名字的模式。
`match` 不会自动忽略大小写或清理空白；输入 `harry` 与 `Harry` 不相等。
区间、不等式或复杂布尔组合仍适合 `if/elif`；更深的解构匹配不在本章范围内。

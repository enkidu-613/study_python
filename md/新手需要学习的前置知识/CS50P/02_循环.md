## 1. 从复制三行到 while

```python
print("meow")
print("meow")
print("meow")
```

这能输出三次，但要改成五百次时，复制代码会把同一个动作散落很多处。
循环不是为了隐藏动作，而是把“做什么”与“做几次”分开。

```python
i = 3
while i != 0:
    print("meow")
    i = i - 1
```

`while` 是控制流语句，每轮先判断条件，为真才执行缩进块，然后回去重新判断。
这里 `i` 是普通整数变量，记录剩余次数；每次循环体的执行叫一轮迭代。
初值为 3，判断时依次看到 3、2、1、0；只有前三次进入循环体。
若删除更新 `i` 的语句，条件会一直成立，产生无限循环。
本例依赖非负初值；不能把 `i != 0` 当成适用于任意输入的循环校验。

## 2. 从零计数与增量赋值

```python
i = 0
while i < 3:
    print("meow")
    i += 1
print("done")
```

`i += 1` 在本例的整数上相当于 `i = i + 1`，不是数学里的自相等式。
条件依次在 `i=0,1,2` 时成立，`i=3` 时为假；循环体恰好执行三次。
计数从零开始是常见约定，不意味着人的“第一轮”必须叫零轮。
`print("done")` 没有缩进到循环内，因此只在循环结束后执行一次。

| 进入本轮前的 `i` | `i < 3` | 本轮动作 | 更新后 |
| --- | --- | --- | --- |
| 0 | 真 | 输出一次 | 1 |
| 1 | 真 | 输出一次 | 2 |
| 2 | 真 | 输出一次 | 3 |
| 3 | 假 | 不进入循环体 | 3 |

改动验证：把 `< 3` 改为 `<= 3`，先预测输出次数，再运行检查是否多了一次。

## 3. for、列表与 range

```python
for i in [0, 1, 2]:
    print("meow", i)
```

`[0, 1, 2]` 是列表字面量，创建有顺序的 `list` 对象。
`for` 每轮从右侧对象取得下一个元素，赋给左侧名字 `i`，再执行循环体。
这里依次取到 0、1、2；不是 Python 自动给 `i` 加一。
若列表是 `[2, 5, 9]`，`i` 就依次得到 2、5、9。

```python
for _ in range(3):
    print("meow")
```

`range` 是内置类型；`range(3)` 创建表示整数范围的对象，供循环依次取得 0、1、2。
它不是先生成一个有三项的列表，不需要为了大次数重复手写所有数字。
终点不包括在内；`range(0)` 没有可迭代的值，循环体一次也不执行。
`range(1, 4)` 可以表示 1、2、3；不要把范围终点误当成最后一个值。
`_` 在这里是普通变量名，惯例表示“这轮的值用不到”，不是特殊的循环指令。
若需要显示本轮的编号，就应使用 `i` 等有意义的名字。
已知重复次数通常用 `for`；直到条件改变才停止，通常用 `while`。

## 4. 字符串重复也是一种简化

```python
print("meow" * 3)
print("meow\n" * 3, end="")
```

第一行得到 `meowmeowmeow`；后面得到三行单独的 `meow`。
字符串乘整数表示重复拼接，不是数值乘法；`\n` 进入字符串后表示换行。
第二次 `print` 关闭默认末尾换行，因为重复的文字已经包含末尾换行，避免再多出空行。
这种写法适合纯文字重复；每轮还要输入、计算或做判断时，用循环更清楚。

## 5. 用户输入：continue 与 break

```python
while True:
    n = int(input("How many times? "))
    if n <= 0:
        continue
    else:
        break

for _ in range(n):
    print("meow")
```

依次输入 `-2`、`0`、`3`：前两次重新询问，第三次离开输入循环，再输出三次。
`while True` 的条件永远为真，但循环仍可由 `break` 主动结束。
`continue` 跳过当前轮剩余代码，回到最近一层循环的下一轮。
`break` 立即退出最近一层循环；这里不会退出整个程序，后面的 `for` 仍会运行。
本版要求严格正整数，所以不能照搬“非负即可”的条件；`0` 不符合本程序的契约。
我们只校验了数值范围。输入 `hello` 会在 `int` 处失败，不会被 `continue` 自动处理。

## 6. 去掉冗余分支，再提取函数

```python
def main():
    n = get_number()
    meow(n)


def get_number():
    while True:
        n = int(input("How many times? "))
        if n > 0:
            return n


def meow(n):
    for _ in range(n):
        print("meow")


if __name__ == "__main__":
    main()
```

无效数字走到循环体末尾后，自然返回下一轮，不一定需要显式 `continue`。
`main` 调用 `get_number`；该函数只在得到正整数时返回；`main` 再把结果传给 `meow`。
`return n` 离开整个 `get_number` 调用，不只是结束当前循环。
`meow` 不负责询问用户，它依照调用者给出的 `n` 重复输出，默认返回 `None`。
这个分工让输入校验集中一处，也让输出函数可以被其他调用者复用。

## 7. 更多列表：下标与遍历

```python
students = ["Hermione", "Harry", "Ron"]
print(students[0])
print(students[1])
print(students[2])
for student in students:
    print(student)
```

先按下标读取三次，再通过循环读取三次，输出的姓名顺序相同。
`students[0]` 是下标访问，读取位置 0 的元素；本列表的有效非负下标是 0、1、2。
列表长度是 3，不意味着下标 3 存在；读取越界会产生 `IndexError`。
`student` 每轮直接得到姓名字符串，不是下标；因此这里不能用无意义的 `_` 替代。
第 0 单元的 `name.split(" ")` 返回的也是这种按顺序存放字符串的列表。

## 8. len：长度与面向人的编号

```python
students = ["Hermione", "Harry", "Ron"]
for i in range(len(students)):
    print(i + 1, students[i])
```

`len` 是内置函数，接收列表，返回元素个数；此处返回整数 3。
先计算 `len(students)`，再创建范围，`i` 依次为 0、1、2。
显示 `i + 1` 让读者看到编号 1、2、3；读取元素仍用真正的下标 `i`。
增加第四个姓名后，循环会根据长度多执行一轮，不用手动修改终点。
如果只要元素值，上一节直接遍历更简单；只有确实需要位置时才引入下标。

## 9. 字典：不要靠两张表的位置维持关系

```python
students = {
    "Hermione": "Gryffindor",
    "Harry": "Gryffindor",
    "Ron": "Gryffindor",
    "Draco": "Slytherin",
}
print(students["Hermione"])
for student in students:
    print(student, students[student], sep=", ")
```

`{key: value}` 创建 `dict` 字典对象，用键关联值；这里姓名是键、学院是值。
如果用一张姓名列表和一张学院列表，增删或排序时很容易让位置错开，破坏对应关系。
字典把一条关联放在一起；查 `students["Hermione"]` 得到 `"Gryffindor"`。
列表通过位置访问，字典通过键访问；字典键不只限于字符串，也可以是整数等合适的对象。
本章不展开键的完整类型限制，但不能认为“字典只能用单词当下标”。
`for student in students` 默认遍历字典的键，不直接返回每个学院，也不是一对键值。
循环体用当前姓名再查到学院；`sep=", "` 控制两个输出对象之间的文字。
键必须唯一；相同键再次赋值会替换对应值，不能自动保存同名学生的多条记录。
读取不存在的键会产生 `KeyError`，不要把它误认为列表下标越界。

## 10. 字典列表与 None

```python
students = [
    {"name": "Hermione", "house": "Gryffindor", "patronus": "Otter"},
    {"name": "Harry", "house": "Gryffindor", "patronus": "Stag"},
    {"name": "Ron", "house": "Gryffindor", "patronus": "Jack Russell terrier"},
    {"name": "Draco", "house": "Slytherin", "patronus": None},
]
for student in students:
    print(student["name"], student["house"], student["patronus"], sep=", ")
```

外层是列表，每个元素是描述一个学生的字典；不是一个更大的单层字典。
`student` 每轮绑定一份字典，所以 `student["house"]` 取的是这一份记录的学院。
`students[0]["name"]` 则先取第一个字典，再按键取姓名，结果为 `"Hermione"`。
`None` 是 Python 的特殊值，表示这里没有具体值；不是空字符串、数字零或文字 `"None"`。
最后一条记录仍然有 `patronus` 这个键，只是值为 `None`；这和键不存在不同。
本章只读取这类数据；增删、排序、字典方法以及推导式留待后续展开。

## 11. Mario：列、行与函数抽象

```python
def print_column(height):
    for _ in range(height):
        print("#")


def print_row(width):
    print("?" * width)


print_column(3)
print_row(4)
```

调用者分别传入高度 3、宽度 4；第一段输出三行 `#`，第二段输出一行 `????`。
列需要每次换行，行可以用字符串重复；不必把两者写成完全一样的实现。
函数把“打印多高一列”“打印多宽一行”命名，使调用者不用每次关心细节。

## 12. 嵌套循环：一行中的每块砖

```python
def print_square(size):
    for row in range(size):
        for column in range(size):
            print("#", end="")
        print()


print_square(3)
```

预期输出三行，每行都是 `###`，没有砖之间的空格。
外层每轮负责一行，内层每轮负责这一行中的一块砖。
每次进入新的外层循环，内层都重新从范围起点取值，不会接着上一行的计数继续。
`print()` 与内层 `for` 对齐：等本行所有砖打印完，再输出一个换行。
若把 `print()` 放进内层，每块砖都会换行；若放到外层之外，所有砖会连成一行。
当 `size=3` 时，内层循环体总共执行 `3 × 3 = 9` 次，不是六次。
`break` 只退出最近一层循环，这一点在嵌套循环中尤其需要区分。

```python
def print_row(width):
    print("#" * width)


def print_square(size):
    for _ in range(size):
        print_row(size)


print_square(3)
```

这个版本把打印一行提取为函数，输出相同；抽象是把细节放到有明确职责的函数里。
前一版适合逐格处理，后一版适合每行完全相同的文字，不存在必须只用某一个的规则。

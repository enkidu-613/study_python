## 先用普通循环，再读缩写

```python
titles = ["  学习  ", "测试"]
cleaned = []
for title in titles:
    cleaned.append(title.strip())
print(cleaned)
```

同一处理可以写成列表推导式（list comprehension）：

```python
cleaned = [title.strip() for title in titles]
print(cleaned)
```

两段都得到 `['学习', '测试']`。执行时先从 `titles` 取一项，绑定给 `title`，计算 `title.strip()`，把结果按顺序放进新列表。写在前面的表达式是“每项生成什么”，后面的 `for` 是“从哪里逐项取”。它创建新列表，不是自动往原列表里追加。

多步判断或需要处理异常时，普通 `for` 往往更容易读；不用为了缩成一行牺牲可读性。

## 序号和当前项目怎么同时得到

```python
for index, title in enumerate(cleaned, start=1):
    print(index, title)
```

`enumerate` 是内置函数，返回迭代器，每次迭代给出一对值，例如 `(1, "学习")`。`index, title` 是解包赋值，把两个值分别绑定给两个变量。`start=1` 决定显示序号从 1 起，不改变列表索引从 0 起的规则。

## 类型注解和入口保护

```python
def format_task(title: str) -> str:
    """返回供终端显示的任务标题。"""
    return title.strip()


if __name__ == "__main__":
    print(format_task("  学习 Python  "))
```

`title: str` 和 `-> str` 是类型注解，供人和静态检查工具理解输入与输出；它们不自动把数字转成字符串，也不自动做运行时校验。函数体第一条三引号字符串是 docstring（文档字符串），用于说明函数职责，可以通过 `help(format_task)` 查看。

`__name__` 是模块中的特殊变量。直接运行这个文件时，它的值是 `"__main__"`，会执行显示结果的代码；通过 `import` 导入时通常是模块名，因而只定义函数、不自动执行这条演示。这使测试可以导入函数而不用回答 `input()`。

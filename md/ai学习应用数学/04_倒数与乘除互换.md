## 1. 心智模型

**倒数 = 两个数乘起来等于 1**。倒数律让乘法和除法可以互换，这是归一化能简化余弦相似度计算的基础。

## 2. 分数基础(前置知识)

### 2.1 分数 = 除法

```
a/b = a ÷ b

例子：
1/2 = 1 ÷ 2 = 0.5
100/2 = 100 ÷ 2 = 50
3/4 = 3 ÷ 4 = 0.75
```

**分数符号 `/` 就是除法的另一种写法**。

### 2.2 分数读法(从下往上读)

```
   分子(上面的数，读最后)
  ───
   分母(下面的数，读第一)

读法：分母 + "分之" + 分子
```

| 分数 | 读法 | 含义 |
|------|------|------|
| 1/2 | 二分之一 | 把 1 分成 2 份，取 1 份 |
| 1/3 | 三分之一 | 把 1 分成 3 份，取 1 份 |
| 2/3 | 三分之二 | 把 1 分成 3 份，取 2 份 |
| 3/4 | 四分之三 | 把 1 分成 4 份，取 3 份 |
| 100/2 | 二分之一百 | 把 100 分成 2 份，取 1 份 |

**中文习惯**：先说"分成几份"(分母)，再说"取几份"(分子)。

### 2.3 分数的三种写法(都是同一个数)

```
1/2 = 1÷2 = 0.5

  1/2     ← 分数写法
  1÷2     ← 除法写法
  0.5     ← 小数写法
```

## 3. 倒数的定义

### 3.1 核心定义

```
两个数相乘等于 1，它们互为倒数。

a × b = 1  →  a 和 b 互为倒数
```

### 3.2 常见倒数对

| 数 | 倒数 | 验证(相乘) |
|---|---|---|
| 2 | 0.5 | 2 × 0.5 = 1 ✅ |
| 5 | 0.2 | 5 × 0.2 = 1 ✅ |
| 10 | 0.1 | 10 × 0.1 = 1 ✅ |
| 4 | 0.25 | 4 × 0.25 = 1 ✅ |
| 0.5 | 2 | 0.5 × 2 = 1 ✅ |
| 1/2 | 2 | (1/2) × 2 = 1 ✅ |

**注意**：2 和 0.5 互为倒数，不是 2 等于 0.5。

### 3.3 找倒数的方法(通用)

```
X 的倒数 = 1 ÷ X

适用于所有数字：
  整数：2 的倒数 = 1÷2 = 0.5
  小数：0.5 的倒数 = 1÷0.5 = 2
  分数：1/2 的倒数 = 1÷(1/2) = 2
  任意数：norm 的倒数 = 1÷norm
```

### 3.4 分数翻转法(分数专用)

```
a/b 的倒数 = b/a
            ↑   ↑
          分母变分子

例子：
1/2 的倒数 = 2/1 = 2
3/4 的倒数 = 4/3 ≈ 1.33
5/8 的倒数 = 8/5 = 1.6
```

**方法**：分子分母交换位置。

### 3.5 特殊情况

| 数 | 倒数 | 说明 |
|---|---|---|
| 2 | 0.5 | 正常 |
| 0.5 | 2 | 互为倒数 |
| 1 | 1 | 1 的倒数是自己(1×1=1) |
| 0 | 不存在 | 0 没有倒数(1÷0 算不出) |

## 4. 倒数律(Multiplicative Inverse Law)

### 4.1 两个核心公式

**公式 1：除法转乘法**

```
y ÷ a = y × (1/a)
        ↑       ↑
     原来的除法  转成乘以 a 的倒数
```

**名字**：除法转化乘法倒数律

**证明**：

```
y ÷ a
= y × 1 ÷ a        ← 任何数 × 1 = 自己
= y × (1÷a)        ← 乘法结合律
= y × (1/a)        ← 1÷a 就是 1/a(a 的倒数)
```

**公式 2：乘法转除法**

```
y × a = y ÷ (1/a)
        ↑       ↑
     原来的乘法  转成除以 a 的倒数
```

**名字**：乘法转化除法倒数律

### 4.2 用数字验证

**验证公式 1**：`y ÷ a = y × (1/a)`

```
10 ÷ 2 = 5
10 × (1/2) = 10 × 0.5 = 5  ✅ 一样
```

**验证公式 2**：`y × a = y ÷ (1/a)`

```
10 × 2 = 20
10 ÷ (1/2) = 10 ÷ 0.5 = 20  ✅ 一样
```

### 4.3 通用模板

```
原数    倒数      关系
 a  ↔  1/a      a × (1/a) = 1

除法 → 乘法：
  y ÷ a = y × (1/a)      "除以 a = 乘以 a 的倒数"

乘法 → 除法：
  y × a = y ÷ (1/a)      "乘以 a = 除以 a 的倒数"

→ 除以一个数 = 乘以它的倒数
→ 乘以一个数 = 除以它的倒数
```

## 5. 乘除法规律(基于倒数律)

### 5.1 核心规律

```
乘以 < 1 的数 = 变小(像除法)
乘以 > 1 的数 = 变大(正常乘法)
除以 < 1 的数 = 变大(像乘法)
除以 > 1 的数 = 变小(正常除法)
```

### 5.2 为什么"乘小数像除法"？

因为**乘以 < 1 的数 = 除以它的倒数**(倒数律公式 1)：

```
10 × 0.5
= 10 × (1/2)      ← 0.5 = 1/2，是 2 的倒数
= 10 ÷ 2          ← 倒数律：乘以倒数 = 除以原数
= 5               ← 变小
```

**0.5 的倒数是 2**，所以乘以 0.5 = 除以 2，结果变小。

### 5.3 为什么"除小数像乘法"？

因为**除以 < 1 的数 = 乘以它的倒数**(倒数律公式 2)：

```
10 ÷ 0.5
= 10 ÷ (1/2)      ← 0.5 = 1/2
= 10 × 2          ← 倒数律：除以倒数 = 乘以原数
= 20              ← 变大
```

**0.5 的倒数是 2**，所以除以 0.5 = 乘以 2，结果变大。

### 5.4 完整对照表

| 算式 | 等价写法 | 结果 | 原因 |
|---|---|---|---|
| `10 × (1/2)` | `10 ÷ 2` | 5 | 乘以 < 1 = 除以倒数 |
| `10 ÷ (1/2)` | `10 × 2` | 20 | 除以 < 1 = 乘以倒数 |
| `10 × 2` | `10 ÷ (1/2)` | 20 | 乘以 > 1 = 变大 |
| `10 ÷ 2` | `10 × (1/2)` | 5 | 除以 > 1 = 变小 |

**对角线相等**，因为乘除通过倒数互换。

### 5.5 用蛋糕理解

```
10 × (1/2) = 5
  问：10 人每人拿半块蛋糕，总共拿了多少？
  答：10 × 0.5 = 5 块(每人拿得少，总数少)

10 ÷ (1/2) = 20
  问：10 块蛋糕每人分半块，能分几人？
  答：10 ÷ 0.5 = 20 人(每人拿得少，分的人多)
```

## 6. 在归一化里的应用

### 6.1 归一化用到倒数律

```
A = [3, 4]    norm = 5

归一化 = A ÷ 5
       = A × (1/5)        ← 倒数律公式 1：÷ 5 = × (1/5)
       = A × 0.2          ← 1/5 = 0.2(5 的倒数)
       = [0.6, 0.8]

→ 两种写法等价，结果都是 [0.6, 0.8]
```

### 6.2 为什么归一化能简化余弦相似度

```
余弦相似度公式：
  cosine(A, B) = dot(A, B) ÷ (norm_a × norm_b)

用倒数律改写：
  = dot(A, B) × [1 / (norm_a × norm_b)]
                   ↑
              这是分母的倒数

归一化提前把这个倒数算进向量里：
  A' = A × (1/norm_a)    ← 用倒数律把 ÷ norm_a 变成 × (1/norm_a)
  B' = B × (1/norm_b)

  dot(A', B') = dot(A, B) × [1/(norm_a × norm_b)]
              = 余弦相似度

→ 归一化用倒数律把"除法"提前变成"乘法"，存进向量里
→ 检索时只算点积(乘法)，不用算除法
```

### 6.3 为什么"除法提前"有好处

```
不归一化(除法在检索时做)：
  对每个文档：dot(Q, D) ÷ (norm(Q) × norm(D))
                          ↑
                       每次都要算 norm + 做除法

归一化(除法在灌库时做)：
  灌库时：D' = D × (1/norm(D))    ← 用倒数律提前算
  查询时：Q' = Q × (1/norm(Q))
  
  对每个文档：dot(Q', D')          ← 只算点积，无除法

省掉了：N 次 norm 计算 + N 次除法(N = 文档数)
```

## 8. 常见坑

### 坑 1：把倒数当成"原数"

```
❌ 错误：1/2 = 2
✅ 正确：1/2 = 0.5，2 是 1/2 的倒数

❌ 错误：0.5 能当 2 用
✅ 正确：0.5 不能当 2 用，但 0.5 是 2 的倒数，乘除可以互换
```

### 坑 2：混淆"原数"和"倒数"

```
10 ÷ 2 = 5          ← 除以原数 2
10 × 0.5 = 5        ← 乘以倒数 0.5
两个结果一样，因为 ÷ 2 = × (1/2) = × 0.5

但：
10 × 2 = 20         ← 乘以原数 2
10 ÷ 0.5 = 20       ← 除以倒数 0.5
两个结果一样，因为 × 2 = ÷ (1/2) = ÷ 0.5
```

### 坑 3：以为 0 有倒数

```
1 ÷ 0 = ?  ← 算不出！

0 没有倒数，因为找不到一个数 × 0 = 1
归一化时如果 norm = 0(零向量)，会报错
```

## 10. 一句话总结

```
分数 = 除法(1/2 = 1÷2 = 0.5)
倒数 = 两数相乘等于 1(2 和 0.5 互为倒数)
倒数律 = 乘除互换的桥梁
  ÷ a = × (1/a)    除以 a = 乘以 a 的倒数
  × a = ÷ (1/a)    乘以 a = 除以 a 的倒数

归一化用到倒数律：
  A ÷ norm = A × (1/norm)
  把"除法"提前变成"乘法"，存进向量
  检索时只算点积(乘法)，不用算除法，快很多
```

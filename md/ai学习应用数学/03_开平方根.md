## 1. 心智模型

开平方根 = 找一个数，它自己乘自己等于原来的数。

```
√9 = 3   因为 3 × 3 = 9
√25 = 5  因为 5 × 5 = 25
```

## 2. 准确术语

### 2.1 三个容易混的名词

| 名词 | 严格含义 | 例子 |
|------|----------|------|
| **开根号** | 总称，泛指"开方运算"（不限定几次） | √9, ∛8 都算 |
| **开平方** | 专门指"开 2 次方" | √9 = 3 |
| **开平方根** | 同"开平方"，更书面的说法 | √9 = 3 |
| **开立方** | 专门指"开 3 次方" | ∛8 = 2 |

### 2.2 符号说明

```
√9      ← 2 默认省略不写，这就是开平方
∛8      ← 左上角小 3，这是开立方
ⁿ√x     ← 左上角小 n，这是开 n 次方
```

### 2.3 平方 vs 开平方根（互为反操作）

| 操作 | 例子 | 反操作 |
|------|------|--------|
| 平方 `x²` | 3² = 9 | √9 = 3 |
| 平方 `x²` | 5² = 25 | √25 = 5 |
| 平方 `x²` | 4² = 16 | √16 = 4 |

就像加法和减法是反操作：
- 加法：3 + 2 = 5 → 减法（反操作）：5 - 2 = 3
- 平方：3² = 9 → 开平方根（反操作）：√9 = 3

## 3. 边界

| 包含 | 不包含 |
|------|--------|
| 正数开平方根 | 负数开平方根（会报错，复数不在本章范围） |
| 整数结果（9→3） | 负数结果（长度永远 ≥ 0） |
| 无理数结果（√2≈1.414） | 开立方（∛8=2） |

## 4. 最小可运行模板

```python
from math import sqrt

# 基本用法
print(sqrt(9))    # 3.0
print(sqrt(25))   # 5.0
print(sqrt(13))   # 3.6055...  (不一定是整数)
print(sqrt(2))    # 1.414...   (无理数也行)

# 负数会报错！
# sqrt(-1)  → ValueError: math domain error
```

### 手写验证（不用 math 库）

```python
def my_sqrt(n, precision=0.0001):
    """用逼近法手算开平方根，验证 sqrt 的结果"""
    if n < 0:
        raise ValueError("负数不能开平方根")
    if n == 0:
        return 0
    low, high = 0, n
    while high - low > precision:
        mid = (low + high) / 2
        if mid * mid > n:
            high = mid
        else:
            low = mid
    return (low + high) / 2

print(my_sqrt(9))   # ≈ 3.0
print(my_sqrt(13))  # ≈ 3.6055
```

## 5. 为什么需要开平方根

### 5.1 在 norm（向量长度）里的作用

norm 公式：`√(所有分量平方之和)`

```
向量 A = [3, 2]

第1步：每个分量平方
  3² = 9
  2² = 4

第2步：求和
  9 + 4 = 13

第3步：开平方根
  √13 ≈ 3.61   ← 这就是 norm(A)
```

### 5.2 为什么需要平方？

因为分量可能是负数（向左走、向下走），但长度不能是负数。平方让负数变正：

```
向量 [-3, -2]  （向左3，向下2）

直接加：-3 + (-2) = -5  ❌ 长度不能是负的

平方后加：(-3)² + (-2)² = 9 + 4 = 13  ✅ 永远是正数
```

### 5.3 为什么需要开平方根？

因为平方把数字放大了，要开平方根缩回来：

```
向量 [3, 2]

第1步：平方  3²=9, 2²=4
第2步：求和  9 + 4 = 13
第3步：开平方根  √13 ≈ 3.61  ← 这才是真正的"箭长"
```

为什么？因为这是勾股定理：

```
横边 = 3，竖边 = 2
对角线 = √(3² + 2²) = √13 ≈ 3.61

       2 ↑
         │ ●
         │╱
         │  ← 这条斜边就是 norm，长度 3.61
     ─────┼───3──→
```

房间宽 3 长 4，对角线 = √(3²+4²) = √25 = 5。一模一样。

## 7. 常见坑

### 坑 1：负数开平方根会报错

```python
from math import sqrt
sqrt(-1)  # ValueError: math domain error
```

原因：实数范围内没有"自己乘自己等于负数"的数。

### 坑 2：开平方根 ≠ 除法

```python
# 开平方根
√9 = 3    # 问：谁×自己=9？

# 除法
9 ÷ 3 = 3  # 问：9 分成 3 份，每份多少？

# 数字碰巧一样，但操作完全不同！
# 验证：√15 ≈ 3.87，但 15÷3 = 5
# → 3.87 ≠ 5，显然不是一回事
```

### 坑 3：开平方根结果不一定是整数

```python
sqrt(9)    # 3.0      ← 整数结果
sqrt(13)   # 3.6055.. ← 无理数
sqrt(2)    # 1.414... ← 无理数
```

大多数情况结果是小数，只有"完全平方数"（1, 4, 9, 16, 25...）才得到整数。

## 9. 类比记忆

```
平方     = 把数字放大（3 → 9）
开平方根 = 把数字缩回原样（9 → 3）

就像：
放大镜 = 把字看大
缩小镜 = 把字看回原样

两者是反操作，配合使用能还原。
```

```
开根号  = 总称（水果）
开平方  = 具体一种（苹果）
开立方  = 另一种（橙子）

说"吃水果"和"吃苹果"在日常对话里没人纠正你
但严格说"苹果"是水果的一种
```

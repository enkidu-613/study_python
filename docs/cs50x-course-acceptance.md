## 审读发现与修补

以下问题在初稿中发现，已要求返修，并纳入最终检查：

- **WARNING：版本来源。** Web 章节曾引用 2025；改按当前 2026 官方内容核对，避免将旧年度当作当前要求。
- **WARNING：数组容量。** 归并示例曾在辅助函数中固定五格临时空间；改由调用者提供对应容量，说明六项练习不能复用五格缓冲。
- **WARNING：内存与文件。** 字符遍历的小改动可能越界，复制目标可能覆盖旧文件；改用合法遍历边界和独占新建目标，并补源文件准备步骤。
- **WARNING：数据结构解释。** 修正 Trie 的 `pytorch` 分叉字符与退化 BST 查找路径；补 `struct`、`->`、双重指针的具体读写关系。
- **WARNING：SQL 的失败路径。** 删除父记录前需处理连接表引用；修正“读旧值再覆盖”与“负库存”的竞态混称。
- **WARNING：练习与代码不一致。** CSV 改成单一 owner 后原来会触发缺失键错误，改用默认零统计。
- **WARNING：Web 示例不足。** 将 API/JSON、会话列表从延伸术语补到可运行程序；注销改为 POST，测试与模板同步。
- **OBS：学习体验。** 统一简体，去掉代理写作过程话，补新符号和调用顺序，明确标准 C 与 CS50 专用环境不同。

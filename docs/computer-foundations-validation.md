## 审核修补

本轮发现并修复的问题包括：

| 问题 | 修补与证据 |
| --- | --- |
| 二分查找的预期次数、字符串比较方向与代码不一致 | 修正为 HTTP 检查 2 次；Missing 先与 Python 比较再与 HTTP 比较，运行及边界断言通过 |
| 独立字典例子依赖前文变量，并可能静默覆盖重复 ID | 补完整数据和重复检查，重复输入实际产生 ValueError |

| 网络章节前篇路径不一致 | 改为实际 05 章文件名，本地链接检查通过 |
| HTTP 非 200 一律视为异常的说法太宽 | 改为本例 404 的默认行为，额外验证成功 202 可正常读取 |
| 错误 HTTP 响应未明确关闭 | 添加 with error，成功和错误路径均可正常清理退出 |
| 异常与自动撤销整组写入容易混淆 | 明确 SQLite 本例唯一冲突仅使语句失败，省略 ROLLBACK 后 RAG 仍在当前事务中，额外运行验证 |

| 跨章范围和数据唯一规则不同 | 说明 07 的标题唯一用于制造错误，综合业务只要求 ID 唯一，允许同名文档 |

修补后未发现阻塞当前课堂实验的问题；这不是对所有操作系统、网络环境或未来版本的无条件保证。

## 已执行验证

- 父代理使用项目现有 Python 3.13.15；从练习目录实际执行 `poetry run python --version` 可找到该环境。示例面向 3.12+，父代理没有逐例在 3.12 下重跑。
- 18 个 Python 代码块均经 AST 语法检查与独立运行，包含四个仅展示数据、无输出的代码块。可观察输出已对照讲义。
- 两个完整 C 示例用现有 `cc -std=c11 -Wall -Wextra` 编译并运行，分别输出 5 和 42。
- 12 项额外边界检查通过：非零子进程转异常、重复 ID 拒绝、线性空输入、二分各项命中与未命中、字典重复拒绝、线程计数再运行、非法路径 404、成功 202、事务成功、外键失败回滚、异常不自动回滚整组、未提交后关闭丢失插入。
- 16 份专项文档及衔接入口检查本地文件链接和代码围栏；固定 JSON 数据可解析，并与三条文档约定一致。
- 抽取的 71 个不同外部资料 URL 均返回 HTTP 200，标题与课程/参考范围相符。可访问不等于逐句支持；机制断言还结合官方参考与运行结果审查。
- 原有 CS50P 讲义未更改正文内容，只增加后续学习指向；AI 主线章节编号不改。

验证器和运行输出位于系统临时目录，不为本次检查新增工具链或应用依赖。

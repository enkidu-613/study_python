# Computer Foundations Practice

这里存放你亲手写的计算机基础练习，不是第二个应用项目，也不需要安装新框架。

对应讲义：[计算机基础](../../md/计算机基础/README.md)。文件名按每章说明创建；目录最初只有本说明与 `documents.json`，没有预先替你完成的综合服务。

从仓库根目录进入：

```bash
cd examples/cs-foundations
poetry run python --version
```

以后用 `poetry run python 文件名.py` 运行自己创建的文件。若不用当前项目，而是在已激活的独立虚拟环境练习，可改用 `python 文件名.py`；不要交叉使用不同环境安装依赖。

讲义用 Python 标准库，目标为 Python 3.12 及以上。网络实验只监听 `127.0.0.1` 并使用系统分配的临时端口；这不是生产服务器。数据库课堂实验默认在内存中，退出即消失，不连接本项目业务数据库。

`documents.json` 是综合练习可用的初始数据。每章完整例子仍自带数据，避免跳章时因缺失上章文件而失败。需要输出文件时用讲义指定的新文件名，不覆盖本项目已有数据。

# CS50P 主题配套：Python 基础示例

这些是 enkidu-613 为本项目中文导学编写的局部机制示例。课程主题参考 David J. Malan 与 CS50 团队（Harvard University）的 [CS50P](https://cs50.harvard.edu/python/)，按 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 分享；[来源、修改说明与许可范围](../../md/新手需要学习的前置知识/CS50P_来源与许可.md)。它们不是官方作业解答。

从仓库根目录执行：

```bash
poetry run python -m pytest examples/python-basics-cs50p/test_task_tools.py -q
```

`task_tools.py` 展示标题清理、分钟数校验和任务编号匹配；`test_task_tools.py` 展示正常与错误路径的测试。它不启动应用或调用模型。

教学入口：[Python 基础路线](../../md/新手需要学习的前置知识/CS50P_Python基础学习路线.md)。完成 [独立结课练习](../../md/新手需要学习的前置知识/CS50P_结课练习_学习待办.md) 时，自己建立练习文件，不将这里的局部示例当成完整成品。

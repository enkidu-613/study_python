# 项目长期记忆 (MEMORY.md)

## 学习项目背景
本仓库是一个 Python / FastAPI / AI 学习项目，用户在此跟随 skill 做系统性学习（含进度管理、章节考试、错题本等）。

## 用户学习画像（重要）
- **数学基础较弱**：用户自述"小学数学都快忘干净了"，公式和符号会构成理解障碍。
- **讲解偏好**：要用最生活化、零公式的类比（网格、人群、地图、一锅汤等），先给直觉再补术语。
- **纠偏方式**：用户会用直觉提问（如"平均池化不是列相加除以行数？"），这类直觉往往针对某种特定池化场景，应先肯定其合理部分，再区分"不同种类的池化"，避免直接否定。
- 曾用 GPT 辅助学习（GPT 称会把理解"同步到学习问题库"，那是 GPT 自身行为，与本项目无关）。

### tool_call_id 与框架注入

- **tool_call_id 是模型生成的**，在 LLM 响应中附带 `tool_calls` 数组，每个 tool call 有独立的 `id`
- 框架转发到 `ToolRuntime.tool_call_id`，工具函数用其构造 `ToolMessage` 完成配对
- `tool_call_id` 不是业务字段，而是框架层的配对凭证（类似快递运单号），不在 `runtime.state` 里
- 并行调用多个工具时，每个 ToolMessage 通过 `tool_call_id` 标识对应哪个 tool call

### Haskell 与函数式编程

- Haskell 是纯函数式、静态类型、惰性求值语言
- 主要用途：编译器/语言工具、金融/区块链（Cardano）、形式化验证、教学
- 在 PL（编程语言理论）领域是"母语"级别的存在
- 入门曲线陡，但 TypeScript 经验能大幅降低难度（ADT、模式匹配、泛型、Option 等概念共通）
- 主要不适应点：没有 class/this、一切都是表达式、惰性求值

### 中间件机制详解

- `@wrap_model_call` 将普通函数变成模型调用前的拦截器，核心是装饰器 + 闭包
- `handler: Callable[[ModelRequest], ModelResponse]` 是框架注入的"通往 LLM 的唯一入口"
- 不调 `handler` 则 Agent 卡住，永远到不了请求模型这一步
- `request.override(...)` 返回新 `ModelRequest`，不修改原对象，保证不可变
- `handler` 类似 Express `next()` 但不同：`next()` 是空手交棒，`handler` 必须传一个 `ModelRequest` 且必须返回 `ModelResponse`；`next()` 是责任链模式，`handler` 是策略模式（直接调 LLM）

### Callable 与泛型

- `Callable` 来自 `collections.abc`，是描述可调用对象的类型注解
- `Callable[[参数类型], 返回类型]` 语法用 `[]` 因为 Python 泛型统一语法
- 自定义泛型类用 `TypeVar` + `Generic[T]`
- 相比 TS 的泛型语法，Python 多一个 `TypeVar` 声明步骤，较繁琐

### Supervisor vs Subagent vs Handoff

- **Handoff（角色切换）**：同一个 Agent 换 prompt 和 tools，共享 State，用 `Command` 改 `active_agent`
- **Supervisor + Subagent**：两个独立 Agent，Subagent 被包装成工具，不对用户说话，结果加工后由 Supervisor 回复
- `Command` 可同时更新多个 State 字段（messages + active_agent），普通工具只能改 messages
- 选择规则：转接客服用 Handoff，叫人查资料回来汇报用 Supervisor

### 硬件检测：_try_tensor

- `_try_tensor(device)` 通过真正创建张量、做运算、同步来验证设备可用性，比只查名字更可靠
- CUDA 异步需要 `torch.cuda.synchronize()` 强制等待 GPU 执行完毕
- 路径一：`FORCE_DEVICE` 环境变量，用户说了算，不测试
- 路径二：`if/elif` 链自动探测，按 CUDA → MPS → DirectML → CPU 优先级降级
- 不直接用循环的原因：每个分支有独特逻辑（CUDA 查显存分 tier、MPS 设环境变量、DirectML 需额外 import）

### DirectML

- 微软推出的底层加速库，让 Windows 上任何支持 DirectX 12 的 GPU 做 ML 加速
- 非 NVIDIA 显卡（AMD、Intel 核显）在 Windows 上的 AI 加速选项

### 代码风格讨论

- `", ".join(tier_map)` 遍历字典 key 生成错误提示
- 条件链用 `if/elif` 平铺直叙，比强行塞循环更清晰

### 教学要点

- **分数符号 `/` 就是除法的另一种写法**：1/2 = 1÷2 = 0.5
- **分数读法**：从下往上读，"分母 + 分之 + 分子"，如 1/2 读作"二分之一"
- **倒数定义**：两个数相乘等于 1，互为倒数(2 和 0.5 互为倒数，不是 2 等于 0.5)
- **倒数律两个公式**：
  - 公式 1(除法转乘法)：`y ÷ a = y × (1/a)`
  - 公式 2(乘法转除法)：`y × a = y ÷ (1/a)`
- **归一化的数学基础**：`A ÷ norm = A × (1/norm)`，用倒数律把"除法"提前变成"乘法"存进向量，检索时只算点积不用算除法
- **知识库同步路径规范**：灌库时 `--path` 必须用绝对路径，避免与历史索引 key 不一致导致重复

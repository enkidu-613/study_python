## 对话 88: 杂项技术问答、恶意网站分析与工具链使用

- 时间: 2026-07-28
- 阶段: multi-agent / dify / 工具链
- 本次内容：
  - **Python 基础回顾**：`default_factory` 避免可变默认值共享陷阱；Python 没有 `new` 关键字；Pydantic BaseModel 的三种实例化方式（直接调用、`**` 字典解包、`model_validate_json`）；`**` 字典解包 vs `*` 列表解包；`json.dumps` / `loads` 序列化；负索引 `[-1]`；`enumerate` 自动编号；对象 vs 字典的区别（`.` vs `[]`）。
  - **类型系统**：`collections.abc` 抽象基类（`Callable`、`Iterable` 等）；`typing_extensions` 向后兼容扩展（`NotRequired`）；`typing` 标准库类型提示；`SecretStr` 保护敏感信息；`raise` 主动抛出异常。
  - **LangChain/LangGraph**：`@tool` 装饰器包装函数为 Tool；`ToolRuntime` 框架自动注入运行时对象（获取 `tool_call_id`、当前 `state`）；`HumanMessage` 不需要传 `role`；`ChatDeepSeek` 参数（model、api_base、api_key、temperature、streaming）；`MessagesState` 是 `TypedDict` 而非对象；`CompiledStateGraph` 编译后的状态图；`builder`（构建器/蓝图）→ `compile()` → `invoke()` 三阶段；`StateGraph` 不是类而是构建器；`ToolNode` 是预置节点类；`active_agent` 是状态标记字符串用于切换角色 Prompt 和 tools。
  - **Dify**：Workflow API 端点应为 `/workflows/run`（带 s）而非 `/workflow/run`；清理 `.pyc` 缓存后重启解决热更新不生效；Maximum Iterations 是循环节点的兜底保护。
  - **项目运维**：SSH 连接 Fedora 需开启 `sshd` 服务；Fedora 安装 `nvidia-container-toolkit` 需先添加 NVIDIA 仓库，Podman 用 `nvidia-ctk cdi generate`；TEI 单模型服务，`/info` 查当前模型，`huggingface-cli scan-cache` 看本地缓存；`text-embeddings-router` 不支持多模型同时运行。
  - **API/HTTP**：`Authorization: Bearer <token>` 中 Bearer 表示令牌类型；Postman `pm.response.stream` vs `pm.response.json()` 取决于响应类型（流式 vs 普通 JSON）；Apifox 脚本设置全局变量用 `pm.globals.set()`；Bearer 之外还有 Basic、Digest 等认证类型。
  - **前端/工具**：macOS 输入法全半角切换 `Shift + 空格`；GitHub CLI (`gh`) 与 `git` 的区别；`pnpm check` 验证依赖一致性；CI（持续集成）vs CD（持续交付/部署）。
  - **网络安全**：分析 `lnnydb.cn`、`91fangwu.com`、`qm.qq.com` 短链接的恶意行为；URL 参数 Base64 解码；多阶段跳转链分析；举报渠道（12321、12377）。
- 相关文件：`app/services/dify_service.py`、`app/routers/langraph_agent.py`、`app/routers/auth.py`、`app/multi_agent.py`、`app/tools/agent_test.py`、`.env`。

- answer_summary: 把 token 隐藏向量排成矩阵，每一行是一个 token，每一列是一个特征维度。平均池化对每一列分别求平均，因此 n 个 token、d 个维度的矩阵会变成一条 d 维文本向量；如果有填充 token，则用 attention_mask 排除填充位置。

### 2026-08-06 20:24 - Hugging Face 生态 - 从基础数学理解平均池化

- id: lq-20260806-2024-pooling-math-from-zero
- chapter: md/32_HuggingFace生态.md
- question: 数学基础忘记后，如何从最初的数学知识理解池化中的逐列求平均？
- answer_summary: 先把单个数字组成有顺序的向量，再把多条同长度向量上下排列成矩阵。矩阵的每一行对应一个 token，每一列对应一个特征维度；逐列求平均就是每列的总和除以 token 数量，最终保留特征维度，得到一条文本向量。
- exact_rule: 数字组成向量，向量组成矩阵；平均池化沿 token 对应的行方向汇总，输出维度等于原隐藏向量维度。
